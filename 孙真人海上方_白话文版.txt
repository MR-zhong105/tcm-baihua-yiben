《孙真人海上方》白话文版
——唐代七言歌诀体验方集，逐首直译

【本书小档案】
| 项目 | 内容 |
|---|---|
| 书名 | 孙真人海上方（一名《海上仙方》《海上秘方》） |
| 署名作者 | 孙思邈（唐，世称"药王""孙真人"）——**实为托名** |
| 真实性质 | 宋明以来民间流传的**单方验方口诀集**，托名孙思邈以广流传。现存最早为明隆庆六年（1572）秦王朱守中刻石本 |
| 体裁 | **七言歌诀**——每首四句，一句一方，好记好传 |
| 内容 | 约 120 首方 + 两首养生铭，涵盖内、外、妇、儿、五官、急救、养生 |
| 原文字数 | 约 7,500 字 |

⚠️ **【读这本书之前，这三句话必须先看】**

1. **这本书不是孙思邈写的。** 它是宋以后民间验方的汇编，托"孙真人"之名流传。把它当成**古代民间偏方的标本**来读，别当成《千金方》那样的医学经典。
2. **书里绝大多数方子今天不能用、也不该用。** 大量方子使用**烧灰（血余炭、乱发烧灰）、动物器官（鼠胆、猫粪、驴粪、虾蟆眼）、矿物毒药（雄黄、朱砂、轻粉、硫黄、芒硝）**，以及**童便、井花水**之类。这些做法**既无疗效证据，又有感染与中毒风险**。
3. **本书的价值在"医学史"和"民俗"层面**：它让我们看到一千年前的普通老百姓，在没有医院、没有药店的地方，用什么办法自救。**它是一面镜子，不是药方本。**

**绝对禁止使用的方子（已在正文逐条标出）**：雄黄（砷）、朱砂（汞）、轻粉（氯化亚汞）、铅丹（铅）、硫黄、芒硝大剂量、砒霜（信石）、斑蝥、木鳖子、草乌、川乌、大戟、蓖麻子，以及所有**粪便类、昆虫类、活体动物**入药方。

【术语小词典】
| 词 | 意思 |
|---|---|
| **井花水** | 清晨第一次汲取的井水（古人认为最清冽） |
| **无灰酒** | 不加石灰澄清的酒（古人认为入药不引入杂质） |
| **烧灰 / 烧存性** | 把药烧成炭但保留"药性"（不完全灰化）——古代常用的炮制法 |
| **研末** | 研成粉 |
| **空心服** | 空腹服 |
| **米饮** | 米汤（用来送服药末） |
| **海上方** | 传说中从海上仙山传来的方子——古人给灵验偏方起的美称 |

◆◆◆ 重刻《海上方》序
═══════════════════════════════════════

【原文】
《孙真人海上方》，洞有旧石刻，第以碑小方多，字画伤于琐屑，不便检阅，且舛讹太甚，乃令生员谢沾细加订正，砻石大书。旧有木刻，病证列于目录，诗首止列号数，读者须寻病于前，而求方于后，尤为不便，兹将病证即列诗首，似亦省目。其他风药论及九转灵丹诸方，洞前已有楷书大碑，兹不复赘及之。
隆庆六年岁在壬申三月之吉 秦王守中识

【白话】
《孙真人海上方》这本书，药王山（"洞"）里本来就有旧的石刻碑，只是因为**碑小而方子多，字刻得细小琐碎，不便于查阅**，而且**错讹太多**，于是命生员（秀才）**谢沾**仔细加以订正，**重新磨平石头、用大字书写**刻碑。

旧有的木刻本，把**病名列在目录里，诗的前面只列号码**，读者得先在前面找到病名、再到后面去找方子，特别不方便。**现在把病名直接列在每首诗的开头**（即作为诗题），似乎更省眼目。

其他的《风药论》以及《九转灵丹》等各种方子，洞前已经有楷书大字碑，这里就不再重复了。

**隆庆六年（1572 年）岁次壬申，三月吉日，秦王朱守中 记**

【译注】
- 这段序交代得很清楚：**这本书是刻在碑上的**。把医方刻石立在药王山（今陕西耀县药王山），供路人抄阅，是古代"公共卫生服务"的一种形式。
- "秦王守中"：明代秦王（藩王）朱守中，隆庆年间在位，主持重刻此碑。
- **体例改进**（把病名列在诗首）是个很实用的编辑思路——相当于给每首诗加了"标题索引"。

◆◆◆ 方一：暑月伤热（中暑）
═══════════════════════════════════════

【原文】
途中大暑最堪怜，急取车轮土五钱，
盏内澄清汤服尽，身轻体健即安然。

【白话】
**主治**：夏天在路上中了暑热（最可怜不过）。
**方子**：赶紧取**车轮上的土（车轮土）五钱**，放在碗里用水搅匀，**澄清之后把上面的清汤喝下去**，身体就会轻健、安然无恙。

【译注】
- **车轮土**：常年被车轮碾压的道上土。古人认为它"经车碾日晒，得土气之正"，能解暑。
- 【现代】**绝不可用**——土里含有大量细菌、寄生虫卵、重金属。中暑的正确处理是：**转移到阴凉处、脱衣散热、补水补盐、物理降温；重症（热射病）立即送医**。

═══════════════════════════════════════
◆◆◆ 方二：伤寒咳嗽
═══════════════════════════════════════

【原文】
伤寒咳嗽夜无眠，细碾明矾末一钱，
半夏橘皮姜共煮，煎汤调下化粘涎。

【白话】
**主治**：外感风寒后咳嗽，夜里睡不着。
**方子**：把**明矾**细细研成一钱末；用**半夏、橘皮（陈皮）、生姜**一起煮汤，**用这个汤送服明矾末**，可以化掉粘痰。

【译注】
- **明矾（白矾）**：硫酸铝钾，有燥湿、化痰、收敛作用。**但含铝，长期或大量服用会导致铝蓄积中毒（与神经系统损害有关）**。现代已极少内服。
- **半夏**：**生半夏有毒**，必须炮制（姜半夏、法半夏）。此处配生姜，正是"生姜解半夏毒"的传统配伍。
- 半夏+陈皮+生姜 = **二陈汤**的核心（燥湿化痰、理气和中），这个组合是合理的。

═══════════════════════════════════════
◆◆◆ 方三：鱼脐疮
═══════════════════════════════════════

【原文】
鱼脐疮毒为难治，火内飞矾地上摊，
寒食面糊才粘贴，生肌退肿即时安。

【白话】
**主治**：鱼脐疮（疮形如鱼脐，指一种红肿剧痛、顶端凹陷的疔疮，很难治）。
**方子**：把**白矾放在火里煅烧（"飞矾"）**，取出摊在地上（去火毒）；用**寒食面（寒食节做的面）调成糊**，把煅矾末和进去，**贴敷在疮上**，能生肌退肿，很快就好。

【译注】
- **"飞矾"**：即煅白矾（枯矾），脱水后收敛燥湿力更强。
- 枯矾外用确实有**收敛、燥湿、抑菌**作用，现代皮肤科仍用于湿疹、足癣等。**相对安全**，但浓度过高会刺激皮肤。
- 鱼脐疮很可能指**痈疽、疖肿**一类。今天这类感染需抗生素治疗。

═══════════════════════════════════════
◆◆◆ 方四：口疮
═══════════════════════════════════════

【原文】
口疮发作痛难言，香麝铜青一处研，
干捻些儿频掺上，不超时刻自安然。

【白话】
**主治**：口腔溃疡发作，痛得说不出话。
**方子**：把**麝香和铜青（铜绿，碱式碳酸铜）**放在一起研细；**干着（不调水）捏一点，频繁地撒在溃疡面上**，不到一会儿就舒服了。

【译注】
- ⚠️ **铜青（铜绿）有毒**——含铜离子，**误服可致恶心呕吐、肝肾损害**。绝对不可内服，外用也应避免。
- 口疮（复发性口腔溃疡）现代多自愈，可用含激素/抗菌的口腔贴膜、漱口水缓解。**不要往嘴里撒矿物粉。**

═══════════════════════════════════════
◆◆◆ 方五：产难（难产）
═══════════════════════════════════════

【原文】
妇人临产十分难，若得良方也不艰，
寻取路傍草鞋鼻，烧灰酒下即时安。

【白话】
**主治**：妇人临产十分困难（难产）。
**方子**：找**路边（丢弃的）草鞋的鞋鼻（鞋面前端的鼻梁部分）**，**烧成灰，用酒送服**，立刻平安。

【译注】
- 这是典型的**民俗疗法**：取"草鞋走过路，能助产下行"的取类比象（鞋主"行"、路旁主"通"）。**无任何疗效依据，且极不卫生。**
- 【现代】难产是**产科急症**，必须住院，由产科医生处理（可能需剖宫产）。延误会母婴双亡。

◆◆◆ 方六：妇人口干
═══════════════════════════════════════

【原文】
妇人口舌并焦干，不治如何得暂安，
寻取黄鸡肝一具，烧灰调酒似灵丹。

【白话】
**主治**：妇人口舌同时焦干（口渴咽干）。
**方子**：找**黄鸡的肝一副，烧成灰，用酒调服**，效如灵丹。

【译注】
- 属"以脏补脏"的取类比象。**无依据、无必要。** 口干应查原因（糖尿病、干燥综合征、药物副作用、脱水等）。

◆◆◆ 方七：眼中流泪（迎风冷泪）
═══════════════════════════════════════

【原文】
迎风冷泪听根原，腊月寻桑不等闲，
若得梢头不落叶，煎汤频洗自然安。

【白话】
**主治**：迎风就流冷泪（泪道不通/泪囊炎一类）。
**方子**：**腊月里去找桑树**（不能随便），**如果能找到枝梢上没落掉的叶子**，**煎汤频频洗眼**，自然就好了。

【译注】
- **桑叶**：疏散风热、清肺润燥、清肝明目。**现代研究**：含黄酮类、生物碱，有抗炎作用。桑叶煎水外洗用于眼疾，在中医眼科沿用已久，**相对安全**（需过滤干净、煮沸灭菌）。
- 迎风流泪常见于**泪道狭窄/阻塞、干眼症、结膜炎**。现代可做泪道冲洗、探通或手术。

═══════════════════════════════════════
◆◆◆ 方八：小便不快
═══════════════════════════════════════

【原文】
小便不快有何难，不用庸医说再三，
匾竹水煎连口咽，方知此法不虚传。

【白话】
**主治**：小便不通畅（排尿困难）。
**方子**：**匾竹（萹蓄）**水煎，连续喝下去，就知道这个法子不虚传。

【译注】
- **萹蓄（biān xù）**：蓼科植物，**利尿通淋、杀虫止痒**，是治疗热淋（尿路感染）的常用药。现代研究证实有**利尿、抗菌**作用。
- ✔ **这是本书中为数不多的、现代仍在使用的有效方之一。** 萹蓄至今仍是中医治疗尿路感染的常用药（如八正散）。
- 【提醒】排尿困难若伴**完全无尿、腰痛发热**，需警惕尿路结石、前列腺增生急性尿潴留、肾功能问题，应就医。

═══════════════════════════════════════
◆◆◆ 方九：大便不快（便秘腹胀）
═══════════════════════════════════════

【原文】
大便不快听吾言，腹满如山起坐难，
用水来研麻子汁，一时吃了自然安。

【白话】
**主治**：大便不通，肚子胀得像山（鼓起），起坐都困难。
**方子**：**用水研火麻仁（麻子）取汁**，一次喝下去，自然就通畅了。

【译注】
- **火麻仁**：桑科大麻的种子，**润肠通便**，富含脂肪油。现代研究证实其**润滑性泻下**作用确切。
- ✔ **有效且相对安全**——至今仍是治疗老年性、体虚性便秘的常用药（麻仁润肠丸即以此为主药）。
- 【提醒】**火麻仁含四氢大麻酚（THC）类成分，大量食用可致头晕、恶心**；且**不可用于肠梗阻引起的"便秘"**。

═══════════════════════════════════════
◆◆◆ 方十：鼻中出血（鼻衄）
═══════════════════════════════════════

【原文】
鼻中衄血涌如泉，乱发烧灰有甚难，
竹管吹将鼻内去，时间恰似遇神仙。

【白话】
**主治**：鼻子出血像泉水一样涌出来。
**方子**：把**乱头发烧成灰**（血余炭），用**竹管吹进鼻子里**，一会儿就止住了，像遇见神仙一样灵。

【译注】
- **血余炭**：人发煅烧成的炭。**中医认为能止血化瘀**，现代研究发现炭化物有**吸附、促凝血**作用。
- ✔ **"吹鼻止血"的思路是对的**（局部压迫 + 促凝），但今天有更安全有效的办法。
- 【现代正确做法】：**坐位、头稍前倾（不要后仰！）、捏住鼻翼软处压迫 10～15 分钟、冷敷鼻梁**；不止血或反复出血需就医（可能是鼻腔血管破裂、高血压、血液病）。

═══════════════════════════════════════
◆◆◆ 方十一：牙疼
═══════════════════════════════════════

【原文】
牙疼齿痛不堪言，得法犹如遇列仙，
大戟烧来疼处咬，名方留下岂虚传。

【白话】
**主治**：牙疼齿痛，痛得说不出话。
**方子**：把**大戟（京大戟）烧过**，放在疼的地方咬住。

【译注】
- ⚠️ **大戟有毒！** 为大戟科植物，含大戟苷，**强烈刺激黏膜，可致口腔肿痛、呕吐、腹泻**；**与甘草相反（配伍禁忌）**。**绝不可用。**
- 【现代】牙痛最常见是龋齿、牙髓炎、智齿冠周炎，需口腔科处理（补牙、根管、拔牙）。

═══════════════════════════════════════
◆◆◆ 方十二：远年咳嗽（久咳）
═══════════════════════════════════════

【原文】
远年咳嗽最难痊，休要求人枉费钱，
但用款冬花作末，烧香一吸便安然。

【白话】
**主治**：多年不愈的咳嗽，最难治好。
**方子**：只要把**款冬花**做成末（或做成烟），**点着熏、吸一口烟**，就能安然。

【译注】
- **款冬花**：润肺下气、止咳化痰，是中医止咳要药。**现代研究**：含款冬二醇等，有镇咳、祛痰、平喘作用。
- 这是**烟熏吸入法**——古代治疗咳喘的一种给药方式（类似现代的吸入疗法）。思路有道理，但**烧烟吸入有呼吸道刺激与致癌风险**。
- ✔ 款冬花本身是有效止咳药，但现代多入煎剂或制成糖浆、颗粒，**不采用燃烟吸法**。

═══════════════════════════════════════
◆◆◆ 方十三：刺毒肿痛
═══════════════════════════════════════

【原文】
刺毒肿痛叫声连，无血无脓不得眠，
研烂松脂为细末，帛封其上免灾愆。

【白话】
**主治**：被刺扎伤后毒肿疼痛，叫唤不停；不出血也不化脓，疼得睡不着。
**方子**：把**松脂（松香）研烂成细末**，用**帛布封贴在上面**，就能免灾。

【译注】
- **松香**：松科树脂，有**燥湿、拔毒、生肌、止痛**作用。外用于痈疽、疖肿是传统用法。
- 【提醒】松香**可能引起接触性皮炎**（过敏）。刺伤后应**清创、取出异物、消毒**，必要时打破伤风针。

═══════════════════════════════════════
◆◆◆ 方十四：刀伤出血
═══════════════════════════════════════

【原文】
刀伤出血不能停，下子秋蛾效最灵，
研碎烧灰伤处贴，即时定止见安平。

【白话】
**主治**：刀伤出血不止。
**方子**：**"下子秋蛾"**（秋天下子的蛾，即蚕蛾一类）效果最灵，研碎烧成灰，贴在伤处，血立刻就止住了。

【译注】
- 蚕蛾烧灰外用止血，属民间经验。**灰类（炭化物）确有吸附促凝作用**，但未经灭菌的昆虫灰敷在开放伤口上**极易感染**。
- 【现代】外伤出血：**直接压迫止血（最重要）+ 清洁包扎 + 抬高患肢**；大出血用止血带（需记录时间）并立即送医。**不要在伤口上撒任何粉剂**（包括香灰、药粉）——会增加清创难度和感染风险。

═══════════════════════════════════════
◆◆◆ 方十五：小儿骨痛
═══════════════════════════════════════

【原文】
小儿骨痛不能言，出血流脓实可怜，
寻取水蛇皮一个，烧灰油拌贴疼边。

【白话】
**主治**：小儿骨头疼痛（不会说），出血流脓，实在可怜。
**方子**：找**水蛇皮一张，烧成灰，用油调拌，贴在疼的地方**。

【译注】
- 小儿"骨痛、出血流脓"很可能是**急性骨髓炎、化脓性关节炎**——这在今天是**必须住院用抗生素治疗的重症**，延误可致残疾。
- 蛇皮烧灰外敷**无效且有感染风险**。

═══════════════════════════════════════
◆◆◆ 方十六：水泻
═══════════════════════════════════════

【原文】
曾闻水泻有何方，焦炒车前子最良，
细末一钱调米饮，只消七剂即安康。

【白话】
**主治**：水样腹泻。
**方子**：**把车前子炒焦（微炒）**，研成细末，**每次一钱，用米汤调服**；只要服七次就好了。

【译注】
- **车前子**：利水通淋、渗湿止泻。**现代研究**：含车前子胶（黏液质），**吸水膨胀，能吸附水分、成形大便**——"利小便以实大便"的现代解释。
- ✔ **有效**：炒车前子治小儿腹泻至今在民间和临床使用，**相对安全**。
- 【提醒】**严重腹泻最怕脱水**——应补充**口服补液盐（ORS）**；若有发热、血便、剧烈腹痛，需就医（可能是细菌性痢疾）。

【白话】

**方子**：取**牛蹄甲，烧成灰，用油拌匀敷在患处**。

【译注】

═══════════════════════════════════════
◆◆◆ 方二十一：破伤风
═══════════════════════════════════════

【原文】
破伤风病莫迟延，脱壳秋蝉三二钱，
紧了牙关难治矣，烧灰酒下便安然。

【白话】
**主治**：破伤风，不可拖延。
**方子**：**脱壳的秋蝉（蝉蜕）二三钱，烧成灰用酒送服**；如果**牙关已经紧闭就难治了**，赶紧用这个还能安然。

【译注】
- **蝉蜕**：疏散风热、息风止痉。**现代研究**：有镇静、抗惊厥作用。中医治疗破伤风（"金疮痉"）常用蝉蜕、全蝎、僵蚕等息风止痉药。
- **"紧了牙关难治矣"**——这个判断**完全正确**：破伤风出现牙关紧闭说明毒素已作用于中枢，病情危重。
- ⚠️ 但**单靠蝉蜕灰治不了破伤风**。【现代】破伤风一旦发作**必须 ICU 抢救**；**关键在预防——受伤后 24 小时内注射破伤风抗毒素/免疫球蛋白 + 彻底清创**。

◆◆◆ 方二十三：蛇伤
═══════════════════════════════════════

【原文】
若人苦被毒蛇伤，独蒜原来力甚良，
切作片儿遮患处，艾烧七炷便安康。

【白话】
**主治**：被毒蛇咬伤。
**方子**：**独头蒜**力道很好，**切成片盖在伤处**，**用艾灸烧七炷**，就好了。

【译注】
- **大蒜**：含大蒜素，有**广谱抗菌**作用，外用对某些细菌感染有效。
- ⚠️ 但**艾灸蛇伤伤口是危险的**：热敷会**加速毒素吸收、加重局部组织坏死**。
- 【现代毒蛇咬伤的正确处理】：
  1. **保持冷静、制动**（减少毒素扩散）；
  2. **去除戒指、手表等束缚物**；
  3. **伤口低于心脏水平**；
  4. **加压固定（pressure immobilization）**，不要切开、不要吸吮、不要冰敷、不要止血带；
  5. **尽快注射抗蛇毒血清**——这是唯一特效治疗。

【白话】
**主治**：被狗咬伤。
**方子**：**刮取砖上的青苔（砖青），和上牛粪**，敷在伤处，立刻就好。

- **狂犬病一旦发作，病死率接近 100%。** 这个方子在最危险的事情上给了最错误的指导——是本书最该警惕的一条。

═══════════════════════════════════════
◆◆◆ 方三十三：自缢（上吊急救）
═══════════════════════════════════════

【原文】
悬梁自缢听根源，急急扶来地上眠，
皂角细辛吹鼻内，须臾魂魄自还元。

【白话】
**主治**：上吊自缢的急救。
**方子**：赶紧把他**扶下来平放在地上**，用**皂角、细辛**研末**吹进鼻子里**（刺激打喷嚏），一会儿魂魄就回来了（苏醒）。

【译注】
- **"急急扶来地上眠"**——**放下、平卧**是对的（解除缢索、恢复体位）。
- 皂角、细辛吹鼻**刺激打喷嚏促醒**——思路是"开窍醒神"，但对**心跳呼吸停止者完全无效**。
- 【现代正确做法】：
  1. **立即解除绳索、确保现场安全**；
  2. **呼叫 120**；
  3. **检查呼吸心跳**；
  4. **无呼吸心跳 → 立即心肺复苏（CPR）**；
  5. 有呼吸但昏迷 → **侧卧位（复苏体位），保持气道通畅，等待急救**。
- **自缢者即使抢救回来，也需心理危机干预**——这条方子在今天读来，最该补充的是"救人之后要救人到底"。

鼠胆寻来倾耳内，真如顷刻遇神仙。

【白话】

**方子**：找**鼠胆**，把胆汁滴进耳朵里，顷刻就能听见。

【译注】
- ⚠️ **动物胆（尤其鼠类）滴耳，有感染、寄生虫风险，且可能携带病原体（如汉坦病毒）**。
- 【现代】耳聋分**传导性**（耵聍栓塞、中耳炎、鼓膜穿孔）与**感音神经性**（老年性、噪声性、突发性）。**突发性耳聋是耳鼻喉科急症——72 小时内用激素治疗有机会恢复，拖延则永久失聪。**

═══════════════════════════════════════

牛甲末儿脐上贴，清清悄悄自然安。

【白话】

**方子**：**牛蹄甲（牛甲）研末，贴在肚脐上**，孩子就清清静静地不哭了。

【译注】

- 【现代】婴儿夜哭要先排查**饥饿、尿布、肠绞痛、中耳炎、发热、佝偻病**等；**持续剧烈哭闹、不可安抚的，需警惕肠套叠、嵌顿疝——这是急症。**

【白话】

**方子**：用**硫黄、白矾**研成细末，**用茄子汁调和**涂搽。

【白话】
**主治**：赤白痢疾。
**方子**：**乌梅七个、大枣七个、栗子壳七个、七寸长的草（疑为某草药）**，再加**灯心草**，**用酒一起煎**，赤白痢立刻就好。

【白话】

◆◆◆ 方四十九：产多（避孕/绝产）
═══════════════════════════════════════

【原文】
麝香肉桂及红花，冰水为丸共一家，
牛膝煎汤来送下，断胎绝产定无差。

【白话】
**主治**：**断胎绝产**（终止妊娠/永久避孕）。
**方子**：**麝香、肉桂、红花**用**冰水做成丸**，**用牛膝煎汤送服**，必定能断胎绝产。

【译注】
- ⚠️⚠️ **这是全书最危险的一条。**
- 麝香 + 红花 + 牛膝都是**强力活血通经、兴奋子宫**的药物，**可导致大出血、流产不全、子宫破裂、DIC（弥散性血管内凝血）、感染性休克、死亡**。
- **没有任何一种"偏方堕胎"是安全的。** 古今中外，自行堕胎一直是孕产妇死亡的主要原因之一。
- 【现代】任何终止妊娠的需求，**必须在正规医疗机构进行**——药物流产（米非司酮+米索前列醇）或手术流产，有严格的适应证、剂量和监护。**避孕请用科学方法（避孕套、短效避孕药、宫内节育器等）。**

═══════════════════════════════════════
◆◆◆ 方五十：来溺（小便不禁）
═══════════════════════════════════════

饭后服时宜米饮，日须两次每三钱。

【白话】
**主治**：小便失禁（不能自控）。
**方子**：找**天台乌药（浙江天台产的乌药最好）研末**，**饭后用米汤送服**，**每天两次，每次三钱**。

【译注】
- **乌药**：行气止痛、温肾散寒。**其"温肾缩尿"的作用用于尿频、遗尿，是中医的经典用法**（如缩泉丸：乌药 + 益智仁 + 山药，至今仍是治疗小儿遗尿、老年尿频的常用方）。
- ✔ **这是本书中比较合理的一条**——乌药配山药、益智仁的"缩泉丸"现代临床确有应用。
- 【现代】尿失禁分**压力性、急迫性、混合性、充盈性**，治疗差异很大（盆底训练 vs 抗胆碱药 vs 手术），应先明确类型。

═══════════════════════════════════════
◆◆◆ 方五十一：骨鲠（鱼刺卡喉）
═══════════════════════════════════════

【原文】
骨鲠难医苦叫天，金樱根用醋来煎。
入喉切莫沾牙上，骨出令人体自便。

【白话】
**主治**：鱼刺/骨头卡在喉咙里，痛苦得叫天。
**方子**：用**金樱根加醋煎**，**喝下去的时候不要沾到牙齿上**，骨刺就出来了，人就舒服了。

【译注】
- "用醋煎"的思路是**醋软化骨刺**——**醋确实可以软化细小的鱼刺，但喝下去那点醋在喉咙停留时间极短，实际效果微乎其微。**
- ⚠️ 【现代正确做法】：**不要吞饭团、不要喝醋、不要用手抠**——这些都可能把刺推得更深、划伤食道。**应该张嘴让人看看能否看到（用镊子取出），看不到就去医院做喉镜/胃镜取出。**
- **鱼刺卡喉的严重并发症**：食道穿孔、纵隔感染、主动脉食管瘘（**可致命**）。

═══════════════════════════════════════

胎前发疟苦难言，寒热交攻最可怜，

【白话】
**主治**：怀孕期间发疟疾（寒热交替），痛苦难言。
**方子**：赶紧取**夜明砂（蝙蝠粪）三钱**，**空腹用茶送服**，自然安然。

【译注】
- ⚠️ **孕妇用药需极其谨慎**；蝙蝠粪**无抗疟作用**且可能带病原体。
- 【现代】疟疾用**青蒿素类复方（ACT）**治疗——**屠呦呦发现青蒿素正是从中医古籍《肘后备急方》得到启发，这是中医对世界的真正贡献**。孕期疟疾须由医生选择安全的抗疟方案。

◆◆◆ 方五十三：血崩（功能性子宫出血）
═══════════════════════════════════════

【原文】
妇人崩漏血何多，管仲还同米炒和，

【白话】
**主治**：妇人血崩、漏下，出血很多。
**方子**：**管仲（贯众）和米一起炒**，**每次服两钱，用酒醋送下**，这个证自然就消了。

【译注】
- **贯众**：清热解毒、凉血止血、杀虫。**现代研究**：有**收缩子宫、止血**作用，中医确用于崩漏。
- ⚠️ 但**贯众有小毒**，部分品种（如绵马贯众）含绵马酸，**过量可致呕吐、腹泻、肝肾损害甚至失明**。
- 【现代】异常子宫出血要查**子宫肌瘤、子宫内膜息肉、腺肌症、凝血功能、内分泌紊乱、子宫内膜癌**——**尤其是绝经后出血，必须排除子宫内膜癌。**

【原文】
痔漏脱肛人受苦，疼痛之时面如土，
急取川椒可二钱，空心水送免凄楚。

【白话】
**主治**：痔漏、脱肛，痛得面如土色。
**方子**：赶紧取**川椒（花椒）约二钱**，**空腹用水送服**，就能免于痛苦。

【译注】
- **花椒**：温中散寒、止痛、杀虫（含挥发油，有局部麻醉作用）。
- ⚠️ 但**二钱（约 6 克）花椒粉内服**对胃肠道**刺激性很强**，可致**恶心、呕吐、胃痛**。
- 【现代】痔的治疗：**增加膳食纤维、多饮水、避免久蹲久坐、温水坐浴**；药物（痔疮栓、地奥司明）；严重者**胶圈套扎、硬化剂注射、手术（PPH、RPH）**。

◆◆◆ 方七十一：吹乳（其二）
═══════════════════════════════════════

【原文】
妇人吹乳意如何，皂角烧灰蛤粉和，
好酒将来调八字，立时痊愈效诚多。

【白话】
**主治**：妇人吹乳（乳腺炎）。
**方子**：**皂角烧成灰，和蛤粉（蛤壳粉）调在一起**，用好酒调服"八字"（一小勺的量），立刻痊愈。

【译注】
- **皂角（皂荚）**：**有溶血作用，内服可致呕吐、腹泻、溶血**，**有毒，不宜内服**。⚠️
- **蛤粉（蛤壳/海蛤壳）**：清热化痰、软坚散结，外用/内服相对安全。
- 【现代】同方六十九：**排空乳汁是关键。**

═══════════════════════════════════════
◆◆◆ 方七十二：疔疮
═══════════════════════════════════════

【原文】
疔疮神效（阙字）草，五月五日午时讨，
细末酒调半两余，服讫汗出果然好。

【白话】
**主治**：疔疮。
**方子**：**某种草（原文脱字，疑为"苍耳草"一类）**神效，**要在五月初五午时采集**；研成细末，**用酒调服半两多**，**服后出汗**，果然就好了。

【译注】
- "五月五日午时采药"是**端午采药**的民俗（古人认为端午阳气最盛，药力最强）。**这是民俗信仰，不是药理学。**
- 【现代】**疔疮（痈、疖、蜂窝织炎）要用抗生素**；**面部的疔疮尤其危险**（"危险三角区"感染可致颅内海绵窦血栓性静脉炎）；**红肿蔓延、发热 = 感染扩散，需急诊。**

◆◆◆ 方七十三：蛇犬伤
═══════════════════════════════════════

【原文】
细辛荜拨及雄黄，用酒研来入麝香，
不问蛇伤并犬咬，当时吃了便安康。

【白话】
**主治**：不管是蛇咬伤还是狗咬伤。
**方子**：**细辛、荜茇、雄黄**，用酒研开，加入**麝香**，吃下去就好了。

【译注】
- ⚠️ **雄黄（砷化物）内服 = 服毒**。⚠️
- **蛇咬伤** → 抗蛇毒血清；**狗咬伤** → 狂犬疫苗。**这两个都不能靠吃药解决。**
- 见方二十三、二十四译注。

═══════════════════════════════════════
◆◆◆ 方七十四：安胎
═══════════════════════════════════════

【原文】
紫苏陈皮橘皮葱，细末砂仁煎酒同，
胎气不安心下揍，腹中胀痛有神功。

【白话】
**主治**：胎气不安，心下（胃脘）痞塞，腹中胀痛。
**方子**：**紫苏、陈皮、橘皮、葱**，加上**砂仁细末**，**用酒同煎**，有神效。

【译注】
- ✔ **这个组合很合理**：紫苏**理气安胎**、砂仁**行气安胎、醒脾**（两者都是中医安胎常用药）、陈皮**理气和胃**。
- 现代研究：砂仁、紫苏均有**缓解胃肠痉挛、抗炎**作用。
- 【现代】孕期腹胀、胎动不安应**产科就诊**；**先兆流产需明确原因（黄体功能、宫颈机能、胚胎本身问题）**，由医生处理。

═══════════════════════════════════════
◆◆◆ 方七十五：颠犬伤（疯狗咬伤）
═══════════════════════════════════════

【原文】
颠犬所伤人最苦，雄黄五钱麝五钱，
酒调二钱作二服，不服灌鼻亦安然。

【白话】
**主治**：被疯狗（狂犬）咬伤，人最痛苦。
**方子**：**雄黄五钱、麝香五钱**，用酒调，**每次二钱，分两次服**；**如果不能口服，就从鼻子灌进去**，也能安然。

【译注】
- ⚠️⚠️ **这是全书最误导的方子之一。**
- **雄黄 = 砷化物，剧毒**；**麝香**价格昂贵且孕妇禁用。这套方案**对狂犬病毫无作用**。
- **狂犬病一旦发病，病死率接近 100%（全球仅极少数存活病例）。**
- 【现代正确处理】：**肥皂水+清水冲洗伤口 15 分钟以上 → 碘伏消毒 → 尽快（最好 24 小时内）接种狂犬疫苗 + 狂犬病免疫球蛋白（III 级暴露）→ 必要时破伤风预防。**
- **这套流程能近乎 100% 预防发病。** 古人不知道狂犬病毒，但今天的我们知道了——**这一条必须当成反面教材。**

═══════════════════════════════════════
◆◆◆ 方七十六：止痛（腹痛心疼）
═══════════════════════════════════════

【原文】
草果玄胡索最先，灵脂没药乳香联，
酒调一盏宜温服，腹痛心疼似手拈。

【白话】
**主治**：腹痛、心疼（胃脘痛）。
**方子**：**草果、延胡索（玄胡索）**为主，配上**五灵脂、没药、乳香**，**用酒调一盏，温服**，腹痛心疼就像被手拈走了一样。

【译注】
- ✔✔ **这是本书中最"专业"的方子之一，配伍非常经典：**
  - **延胡索**：活血行气止痛——**"专治一身上下诸痛"**，现代研究证实延胡索乙素有**确切的镇痛、镇静作用**（不成瘾）；
  - **乳香 + 没药**：活血行气、消肿止痛（经典药对）；
  - **五灵脂**（鼯鼠粪）：活血止痛；
  - **草果**：燥湿温中。
- 这个组合就是**"手拈散"**（延胡索、五灵脂、草果、没药）的原型——**至今仍是中医治疗胃脘痛、痛经、跌打痛的常用方**。
- 【提醒】**五灵脂为动物粪便，现代多不使用**；**乳香没药有胃肠道刺激**；**更重要的是——腹痛必须先排除急腹症（阑尾炎、宫外孕、肠梗阻、胃穿孔），止痛药会掩盖病情。**

凡人痔漏痛成疮，遗种蚕蛾纸半张，

◆◆◆ 方七十八：牙疼（其三）
═══════════════════════════════════════

【原文】
寒菊花儿五七团，雪花同捣饭为丸，
搐入鼻中如枣大，去疼真似手来拈。

【白话】
**主治**：牙疼。
**方子**：**寒菊花（野菊）五七朵**，和**雪花（或"朴硝"，一说为雪水）**一起捣，用饭做成丸，**像枣子那么大，塞进鼻孔里**，去疼就像用手拈掉一样。

- "搐鼻"（塞鼻）是中医的外治法之一（**鼻黏膜吸收快**）。
- 但塞鼻取效治牙痛**证据不足**，且有**误吸风险**。
- 【现代】牙痛看牙医。

◆◆◆ 方七十九：接骨
═══════════════════════════════════════

【原文】
接骨谁知甚药佳，急须觅取大虾蟆，
生捣如泥涂患处，杉皮夹定甚堪夸。

【白话】
**主治**：接骨（骨折）。
**方子**：赶紧找**大蟾蜍（虾蟆）**，**生捣成泥涂在患处**，用**杉树皮夹板固定**——这个办法很值得夸。

【译注】
- ⚠️ **蟾蜍有毒**（蟾蜍毒素），**生捣外涂于破损皮肤可致吸收中毒**（心律失常）；若皮肤有伤口更危险。
- ✔ **"杉皮夹定"是本书这条方子里真正有价值的部分**——**骨折固定**才是关键（见《金疮秘传禁方》《跌打秘方》的小夹板法）。
- 【现代】骨折：**复位 + 固定 + 功能锻炼**。固定靠石膏/夹板/手术内固定，**外敷蟾蜍泥只会增加中毒和感染风险**。

═══════════════════════════════════════
◆◆◆ 方八十：解酒
═══════════════════════════════════════

【原文】
酒能醒酒不寻常，草果加煎干葛汤，
解毒频频三四盏，醒前醉后并宜尝。

【白话】
**主治**：解酒。
**方子**：**草果加上干葛（葛根）煎汤**，频频服三四盏，醉前醉后都可以喝。

【译注】
- ✔✔ **葛根解酒是有依据的**：
  - **葛根**（含葛根素、大豆苷等黄酮）能**加速乙醇代谢、保护胃黏膜、缓解头痛**；
  - 现代研究证实葛根提取物可**降低血醇浓度、减轻酒精性肝损伤**；
  - 中医"葛花解酲汤"就是专治酒积的方子（葛花、砂仁、白豆蔻等）。
- **草果**：燥湿温中，缓解醉酒后的恶心呕吐。
- ✔ **这条方子是靠谱的。** 当然，**最好的解酒是不喝或少喝**。

═══════════════════════════════════════
◆◆◆ 方八十一：忘事（健忘）
═══════════════════════════════════════

【原文】
凡人日夜事多忘，远志菖蒲煮作汤，
每旦空心服一碗，诗书如刻在心肠。

【白话】
**主治**：记性不好，整日忘事。
**方子**：**远志、石菖蒲**煮成汤，**每天早上空腹服一碗**，读过的诗书就像刻在心肠里一样。

【译注】
- ✔✔ **"远志 + 菖蒲"是中医益智开窍的经典药对，沿用至今：**
  - **远志**：安神益智、祛痰开窍。**现代研究**：远志皂苷有**改善学习记忆、抗痴呆、神经保护**作用；
  - **石菖蒲**：开窍豁痰、醒神益智。**现代研究**：β-细辛醚有**中枢兴奋、改善记忆**作用。
  - 两味配伍名"**开心散**"（远志、菖蒲、人参、茯苓），孙思邈《千金方》里就有"开心散"治健忘——**这一条倒真的与孙真人有关**。
- 【提醒】**石菖蒲挥发油含 α-细辛醚，有一定毒性争议，不宜长期大剂量**；**健忘也可能是甲减、抑郁、睡眠障碍、早期痴呆的表现，应查明原因。**

◆◆◆ 方八十二：果毒（食物中毒）
═══════════════════════════════════════

【原文】
世间果品甚多般，性毒有无冷与寒，
误食中伤何可解，朴硝加麝即时安。

【白话】
**主治**：误食果品中毒。
**方子**：**朴硝（芒硝）加麝香**服下，立刻就好。

【译注】
- **芒硝（硫酸钠）**：**容积性泻药**——**通过导泻加速毒物排出**，思路是对的（类似现代口服硫酸钠导泻用于某些中毒）。✔
- ⚠️ 但**芒硝用量过大可致严重腹泻、脱水、电解质紊乱**；**麝香孕妇禁用**。
- 【现代】食物中毒：**停止进食可疑食物 → 补充水分/电解质 → 保留可疑食物样本 → 就医**；**细菌性食物中毒（如肉毒杆菌、金黄色葡萄球菌）需特效治疗**。

═══════════════════════════════════════

【原文】
老幼忽然吃噫连，川椒生面和为丸，
醋汤十粒梧桐大，信是仙方不妄传。

【白话】

**方子**：**川椒和生面粉**和在一起做成丸，**用醋汤送服十粒**（梧桐子大）。

═══════════════════════════════════════
◆◆◆ 方八十四：伤寒
═══════════════════════════════════════

【原文】
伤寒忽觉苦难医，半两茱萸不用余，
用水煎来空腹服，管教所患当时除。

【白话】
**主治**：忽然觉得伤寒（外感寒邪）难受。
**方子**：**吴茱萸半两**（不用别的），**用水煎，空腹服**，病立刻就除。

【译注】
- **吴茱萸**：散寒止痛、降逆止呕、助阳止泻。含**吴茱萸碱、吴茱萸次碱**，有**镇痛、抗炎、抗溃疡**作用。
- ✔ 用于**寒邪犯胃的呕吐、头痛（厥阴头痛）、腹泻**是合理的。
- ⚠️ 但**吴茱萸有小毒**（大量可致**视力障碍、错觉、呕吐**），**半两（约 15 克）剂量偏大**；**阴虚火旺者禁用**；**孕妇慎用**。
- 【提醒】"伤寒"在古代是广义的外感热病总称，**绝不是单味药能解决的**。持续发热必须就医。

◆◆◆ 方八十五：头空痛（头顶痛）
═══════════════════════════════════════

【原文】
脑痛悬空在顶高，急宜细碾马牙硝，
好把酥来同捣合，暂安鼻上自逍遥。

【白话】
**主治**：头痛悬在头顶最高处（巅顶痛）。
**方子**：赶紧把**马牙硝（芒硝的精制品）**细细碾碎，和**酥油（酥）**一起捣匀，**暂时敷在鼻子上**，自然就舒服了。

【译注】
- 芒硝**清热软坚**，外敷于鼻（**鼻黏膜吸收 / 清热降火**）——思路是"上病下取、导热下行"。
- 外用相对安全，但**疗效不确定**。
- 【现代】巅顶痛需排查**高血压、颈椎病、偏头痛、颅内病变**。

═══════════════════════════════════════
◆◆◆ 方八十六：赤眼（急性结膜炎）
═══════════════════════════════════════

【原文】
赤眼难开不见天，宣州土产好黄连，
便将驴乳淹三宿，点上光明即豁然。

【白话】
**主治**：红眼病（眼睛红肿睁不开）。
**方子**：用**宣州（安徽宣城）产的好黄连**（道地药材），**用驴乳浸泡三夜**，**取来点眼**，立刻就光明豁然。

【译注】
- ✔ **黄连（宣黄连为道地药材）+ 乳汁浸 + 点眼**——**黄连含小檗碱，有确切的广谱抗菌作用**，用于细菌性结膜炎是有道理的。
- **"用乳汁浸"**：乳汁作为溶剂（**脂溶性成分易溶出 + 缓和刺激 + 润滑**），古人这步处理很讲究。
- ⚠️ 但**生乳汁可能带菌（如布鲁氏菌、结核杆菌）**，滴眼不安全。
- 【现代】细菌性结膜炎用**抗生素滴眼液（左氧氟沙星、妥布霉素）**；**病毒性结膜炎（红眼病）以隔离、冷敷、人工泪液为主，抗生素无效**。

═══════════════════════════════════════
◆◆◆ 方八十七：翳眼（角膜翳）
═══════════════════════════════════════

【原文】
眼中生翳莫能窥，想是肝经蕴热虚，
缓存兰香七个子，煎汤一服病消除。

【白话】
**主治**：眼睛生翳障，看不清东西。

- **刘寄奴**：活血通经、散瘀止痛、止血消肿、消食化积。**是伤科要药**（传说南朝宋武帝刘裕小名寄奴，发现此药，故名）。
- ✔ **现代研究**：刘寄奴有**止血、抗炎、改善微循环**作用。

- **无痛性肉眼血尿是膀胱癌的典型信号，必须做膀胱镜！** 一句"自然无"可能耽误一条命。

【原文】

【白话】

**方子**：**阿胶用灰（蛤粉/蒲黄）炒成珠状**（"阿胶珠"炮制法），**趁热立刻研成末**，月经不调适合用这个末，**用酒调服一剂**，应时痊愈。

**主治**：小儿腹泻、痢疾兼脱肛，不用着急。
**方子**：**槐花研成末，用米汤调**；**饭前服一盏，频频进服**，效果像鼓槌敲鼓一样应声而响。

【译注】
- ✔ **槐花（槐米）**：凉血止血、清肝泻火。**现代研究**：含**芦丁（芸香苷）、槲皮素**，有**抗炎、止血、保护血管**作用；**用于便血、痔血、痢疾是合理的。**
- ✔ 米汤调服还能**补充水分与电解质**——对腹泻患儿是有益的。
- 【现代】小儿腹泻：**口服补液盐（ORS）+ 补锌 + 继续喂养**；**细菌性痢疾需抗生素**；**血便 + 高热需警惕溶血尿毒综合征（HUS）**。

═══════════════════════════════════════
◆◆◆ 方一二一：牙疼（其四）
═══════════════════════════════════════

【原文】
牙疼鹤虱共甘松，白芷细辛分两同，
为末少将牙上擦，煎汤灌漱自安宁。

【白话】
**主治**：牙疼。
**方子**：**鹤虱、甘松**，加上**白芷、细辛（分量相同）**，研成末，**取少许擦在牙上**；**再煎汤含漱**，自然安宁。

【译注】
- ✔ **这个方子配伍不错**：
  - **细辛**：**局部麻醉、镇痛**（含挥发油）；
  - **白芷**：**镇痛、抗炎**（含香豆素类）；
  - **甘松**：理气止痛；
  - **鹤虱**：杀虫（古人认为牙痛是"虫牙"——**这与现代"龋齿是细菌感染"的认识有相通之处**）。
- 现代的**中药牙膏、牙痛水**里常含细辛、白芷、丁香等成分，**思路一脉相承**。
- ⚠️ 但**细辛含马兜铃酸类成分，有肾毒性**，**外用也不可长期大量**。
- 【现代】牙病看牙医——**这才是根本。**

═══════════════════════════════════════
◆◆◆ 附一：孙真人枕上记
═══════════════════════════════════════

【原文】
侵晨一碗粥，夜饭莫教足。
撞动景阳钟，扣齿三十六。
大寒与大热，且莫贪色欲。
醉饱莫行房，五脏皆翻覆。
艾火漫烧身，争如独自宿。
坐卧莫当风，频于暖处浴。
食饱行百步，常以手摩腹。
莫食无鳞鱼，诸般禽兽肉。
自死兽与禽，食之多命促。
土木为形象，求之有恩福。
父精母血生，那忍分南北。
惜命惜身人，六白光如玉。

【白话】
（这是一首**五言养生歌**，讲日常起居的宜忌）

| 原文 | 白话 |
|---|---|
| 侵晨一碗粥，夜饭莫教足 | 早晨喝一碗粥；晚饭不要吃得太饱 |
| 撞动景阳钟，扣齿三十六 | 听到晨钟（景阳钟）响起，就叩齿三十六下 |
| 大寒与大热，且莫贪色欲 | 极寒极热的时节，不要贪恋房事 |
| 醉饱莫行房，五脏皆翻覆 | 酒醉、过饱时不要行房，会让五脏翻覆受损 |
| 艾火漫烧身，争如独自宿 | （与其）用艾灸遍烧身体，不如**独自安睡** |
| 坐卧莫当风，频于暖处浴 | 坐卧不要当风；常在温暖的地方沐浴 |
| 食饱行百步，常以手摩腹 | 吃饱后走一百步；常常用手按摩腹部 |
| 莫食无鳞鱼，诸般禽兽肉 | （一说：）不要吃无鳞的鱼；各种禽兽肉也要节制 |
| 自死兽与禽，食之多命促 | **自己死掉的兽类和禽类，吃了会短命**（病死、不明死因的畜禽） |
| 土木为形象，求之有恩福 | 用土木塑造（神佛）形象、祈求，自有恩福 |
| 父精母血生，那忍分南北 | 都是父精母血所生，怎么忍心分出南北（亲疏） |
| 惜命惜身人，六白光如玉 | 爱惜性命身体的人，（面色）光洁如玉 |

【译注】
- ✔ **前八句的养生原则，放到今天依然正确**：
  - **早餐吃粥、晚餐七分饱** —— 符合现代"晚餐少、早餐好"的建议；
  - **叩齿** —— 现代认为可促进牙周血液循环、唾液分泌；
  - **寒热极端时、醉饱时不行房** —— 减少心血管意外风险；
  - **坐卧不当风** —— 避免受凉、面神经麻痹；
  - **饭后散步、摩腹** —— 促进胃肠蠕动（"饭后百步走"）；
  - **自死畜禽不可食** ✔✔ —— **这条最重要**：病死、不明死因的动物**可能携带炭疽、狂犬病、禽流感等人畜共患病**，**今天依然是食品安全的基本原则**（"病死畜禽必须无害化处理，严禁食用"）。
- **"六白"**：一说指牙齿、指甲、面色等洁白有光泽，是健康的表现。
- 末几句"土木为形象""分南北"带有**劝善、伦理**色彩，与养生主题略有跳跃（可能是刻碑时混入）。

═══════════════════════════════════════
◆◆◆ 附二：孙真人养生铭
═══════════════════════════════════════

【原文】
怒甚偏伤气，思多太损神。
神疲心易役，气弱病相侵。
勿被悲欢极，当令饭食均。
再三防夜醉，第一戒晨嗔。
亥寝鸣云鼓，寅兴漱玉津。
妖邪难犯己，精气自全身。
若要无诸病，常当节五辛。
安神宜悦乐，惜气保和纯。
寿夭休论命，修行本在人。
若能遵此理，平地可朝真。

【白话】

| 原文 | 白话 |
|---|---|
| 怒甚偏伤气，思多太损神 | 发怒太过会伤气，思虑太多会损神 |
| 神疲心易役，气弱病相侵 | 精神疲惫，心就容易被（外物）役使；正气虚弱，疾病就会侵袭 |
| 勿被悲欢极，当令饭食均 | 不要让悲欢走到极端；饮食应当均衡 |
| 再三防夜醉，第一戒晨嗔 | 再三提防夜里喝醉；**第一要戒的是早晨发怒** |
| 亥寝鸣云鼓，寅兴漱玉津 | 亥时（21～23 点）入睡，睡前"鸣天鼓"；寅时（3～5 点）起床，漱"玉津"（吞咽唾液） |
| 妖邪难犯己，精气自全身 | 邪气难以侵犯自己，精气自然保全全身 |
| 若要无诸病，常当节五辛 | 想要不生各种病，应当常节制"五辛"（葱、蒜、韭、薤、兴渠等辛辣荤腥） |
| 安神宜悦乐，惜气保和纯 | 安定心神宜愉悦快乐；爱惜正气、保持和畅纯净 |
| 寿夭休论命，修行本在人 | 长寿短命别只说"命"，修行（养生）根本在于人自己 |
| 若能遵此理，平地可朝真 | 如果能遵守这些道理，平地上也能朝见真人（成仙得道） |

【译注】
- ✔✔ **这首《养生铭》是全书最有价值的部分之一**——它的养生观朴素、理性、可执行，而且**和现代健康生活方式高度吻合**：
  - **情绪管理**："怒甚伤气、思多损神、勿被悲欢极、戒晨嗔"——**情绪应激与心血管疾病、消化性溃疡、免疫功能的关联已被现代医学反复证实**；
  - **饮食均衡**："当令饭食均""常当节五辛"——**膳食均衡、少辛辣**；
  - **限酒**："再三防夜醉"——**限酒是现代最重要的健康建议之一**；
  - **规律作息**："亥寝寅兴"——**早睡、规律作息**（虽然寅时 3～5 点起太早，但"早睡"这个方向是对的）；
  - **叩齿吞津**："鸣云鼓、漱玉津"——**现代认为可促进唾液分泌、保护牙周、助消化**；
  - **主观能动性**："寿夭休论命，修行本在人"——**这是最精彩的一句**：**健康不靠命，靠自己的日常修行。** 在命定论盛行的时代，这句话相当有力量。
- **"鸣天鼓"**：传统养生法——双手掩耳，食指弹后脑（风池、玉枕一带）各 24 下，有**醒神、聪耳、缓解头晕**之效，至今流传。
- **"漱玉津"（吞津）**：舌搅口腔、鼓漱，待唾液满口后分次咽下。现代认为唾液含**淀粉酶、溶菌酶、表皮生长因子**，有助消化与口腔健康。

**1. 这本书到底是什么？**
它不是孙思邈的著作，而是**宋明时代民间验方的口传汇编**，托名"孙真人"便于流传，后来被**刻在药王山的碑上**（明隆庆六年秦王朱守中重刻）。用七言歌诀写成，是为了**让不识字的老百姓也能口口相传**——这就是为什么它叫"**海上**方"（海上传来的仙方，一听就灵）。

**2. 一百二十多首方子，今天还能用的有几条？**
老实说，**真正配伍合理、现代仍在沿用的，大约只有十来条**：

| 方 | 药物 | 现代评价 |
|---|---|---|
| 头风痛 | 川芎、白芷、石膏（芎芷石膏汤） | ✔ 至今常用，治偏头痛 |
| 忘事 | 远志、菖蒲（开心散） | ✔ 至今常用，益智开窍 |
| 解酒 | 葛根、草果 | ✔ 葛根解酒有研究支持 |
| 止痛 | 延胡索、乳香、没药、五灵脂（手拈散） | ✔ 延胡索镇痛确切 |
| 自汗 | 防风、浮小麦 / 牡蛎散 | ✔ 至今常用 |
| 小便不快 | 萹蓄 | ✔ 利尿通淋，治尿路感染 |
| 大便不快 | 火麻仁 | ✔ 润肠通便，麻仁丸主药 |
| 水泻 | 炒车前子 | ✔ 吸附止泻，安全有效 |
| 消渴 | 天花粉 | ✔ 中医治糖尿病主药之一 |

| 方 | 危险成分 | 后果 |

| 蚊虱 | 燃烧雄黄 | **砷烟雾吸入中毒** |

**4. 一句话总评**
《海上方》是**一千年前中国老百姓的"家庭偏方手册"**。它里面有珍珠（芎芷石膏汤、开心散、手拈散），也有大量的沙子和毒药。

**它的价值不在"能不能照着用"，而在让我们看到：在没有医院、没有药店的年代，普通人面对疾病时，是怎样用身边仅有的一切——草根、树皮、灶土、甚至粪便——拼尽全力自救的。**

这份挣扎，值得被记住。**但这本书，不应该被当成药方本使用。**
