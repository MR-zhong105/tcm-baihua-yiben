《针经节要》白话文版

【本书简介】
《针经节要》一卷，元代杜思敬编撰，成书于公元 1315 年（元延祐二年）。杜思敬是元代官员兼医家，他编纂的《济生拔粹》丛书收录了金元时期十九位名医的著作，《针经节要》就是其中一种。

书名里的"针经"，指的是《黄帝内经·灵枢》——宋代以前《灵枢》多称《针经》，因为它的核心内容是经络与针刺。"节要"就是节选提要。所以这本书本质上是**《灵枢》经络腧穴部分的精华摘编**，加上《铜人腧穴针灸图经》的穴位主治内容，编成一部便于临证的针灸手册。

全书分三大部分：
- **总论**：十二经气血多少、络脉五色诊法
- **十二经是动所生之病**：十二条经脉各自发病时的证候（这是《灵枢·经脉》的核心内容）
- **十二经穴治证**：每条经脉四肢肘膝以下的五输穴（井、荥、俞、经、合）加原穴的定位与主治

这本书篇幅不大，但把针灸最核心的"经脉辨证 + 五输穴运用"浓缩在一起，是学习针灸很好的入门阶梯。

【阅读须知】
- **"是动病"与"所生病"**是《灵枢·经脉》特有的分类：是动病多指经脉气机变动引发的急性、外经病症；所生病多指该经所属脏腑及其循行部位发生的慢性、实质性病症。简单记：**是动病偏气、偏外、偏急；所生病偏血、偏里、偏缓**。
- **五输穴**是十二经在四肢肘膝以下的五类特定穴，按经气由小到大的流注次序排列：井（经气初出，如水的源头）、荥（经气稍盛，如小水流）、俞（经气灌注，如水流汇聚转输）、经（经气盛大流通，如江河畅通）、合（经气汇合入脏，如百川入海）。另有"原穴"，是原气经过留止之处，六阳经各有一原穴。
- 书中穴位的**针刺深度与灸疗壮数**是元代度量衡与古代针具标准，现代针灸有更规范的消毒与操作要求，**不可照书自行施针**。针灸必须由具备执业资质的医师操作。
- 原电子文本存在缺字与条目错位（足阳明胃经的穴位被误置于足太阴脾经篇内），译文中已逐一指出并补正。

【卷上】总论

◆ 一、十二经气血多少

【原文】
黄帝问曰：十二经中气血多少，可得闻乎？岐伯对曰：其可度量者，中度也，以经水应十二经脉也。溪谷远近浅深，气血多少各不同。其治以针灸，各调其气血，合而刺之，补虚泻实，皆须尽知其部分也。

肝足厥阴经：少气多血
心手少阴经：少血多气
脾足太阴经：少血多气
肺手太阴经：少血多气
肾足少阴经：少血多气
胆足少阳经：少血多气
小肠手太阳经：多血少气
胃足阳明经：多血多气
大肠手阳明经：多血多气
膀胱足太阳经：多血少气
心包络手厥阴经：多血少气
三焦手少阳经：多气少血

【白话】
黄帝问道：十二经脉中气血的多少，可以讲给我听吗？

岐伯回答说：这些是可以度量推断的，有一个衡量的标准——就是用地面上十二条河流来类比人体十二经脉。就像河流有长短、宽窄、深浅的差别一样，人体经脉所在部位的肌肉间隙（溪谷）也有远近浅深的不同，其中运行的气血多少自然各不相同。

用针灸治疗时，就是要**各按其气血多少的情况来调理**：该补的补、该泻的泻，把气血调至平衡而后施针。补虚泻实的关键，在于**完全掌握每条经脉的分布部位与气血特点**。

**十二经气血多少一览表：**

| 经脉 | 气血特点 | 记忆要点 |
|---|---|---|
| 足厥阴肝经 | 少气多血 | 肝藏血，故血多气少 |
| 手少阴心经 | 少血多气 | 心主血脉而火性主动，气旺 |
| 足太阴脾经 | 少血多气 | 脾主运化气机 |
| 手太阴肺经 | 少血多气 | 肺主气，故气多 |
| 足少阴肾经 | 少血多气 | 肾为气之根 |
| 足少阳胆经 | 少血多气 | 胆主疏泄，气机为主 |
| 手太阳小肠经 | 多血少气 | 小肠受盛化物，血分为主 |
| **足阳明胃经** | **多血多气** | **气血俱盛，最宜放血、可深刺** |
| **手阳明大肠经** | **多血多气** | **气血俱盛** |
| 足太阳膀胱经 | 多血少气 | 太阳为巨阳，血分充盛 |
| 手厥阴心包络经 | 多血少气 | 代心行血 |
| **手少阳三焦经** | **多气少血** | **主气机水道，宜浅刺、不宜出血** |

【译注】
- **"以经水应十二经脉"**：古人把人体十二条经脉比作地上的十二条河流（清、渭、海、湖、汝、渑、淮、漯、江、河、济、漳等）。这不是修辞游戏，而是一种思维方式——认为人体与自然同构，河流水量有大小，经脉气血也有多少。
- **气血多少的临床意义**：
  - **多血多气之经（阳明）**：可以深刺、留针，也可以放血。所以中风、实证热证常用阳明经穴。
  - **多气少血之经（少阳）**：宜浅刺，慎出血。故少阳经穴多用浅刺、少出血。
  - **少气多血之经（厥阴）**：可出血，不宜过度耗气。
  - **少血多气之经（太阴、少阴）**：宜调气为主，不宜出血。
  - 这套规则出自《灵枢·经水》，是古人"因经制宜"的体现。
- **现代理解**：气血多少可粗略对应不同部位组织的血管密度与神经分布特点。例如阳明经循行区域（面部、胸腹、下肢前侧）血供丰富；少阳经循行区域（侧头、胁肋、下肢外侧）神经末梢密集而血管相对较少。这个观察是有解剖基础的。

◆ 二、络脉五色诊法

【原文】
视其部中浮络，其色多青则痛，多黑则风痹，黄赤则热，多白则寒，五色皆见，寒热也。感虚则留于筋骨之间，寒多则筋挛骨痛，热多则骨消筋缓也。

【白话】
观察病变部位浮现于皮下的细小络脉（浮络），可以根据颜色判断病情：
- 络脉**多呈青色**：主痛证；
- 络脉**多呈黑色**：主风痹（风寒湿痹阻经络）；
- 络脉**黄赤色**：主热证；
- 络脉**多呈白色**：主寒证；
- **五色同时出现**：是寒热错杂的病症。

如果邪气乘虚侵入，就会留滞在筋骨之间。**寒邪偏盛**，就会筋脉拘挛、骨节疼痛；**热邪偏盛**，就会骨骼消损、筋脉弛缓无力。

【译注】
- **浮络望诊**是中医独特的诊断法：观察皮肤表面可见的细小血管（尤其小儿食指络脉、舌下络脉、下肢曲张静脉等）的颜色变化来推断病情。现代看，这实质上是观察**局部血液循环与血氧饱和度**的状态：
  - 青紫 → 静脉淤血、缺氧（痛证常伴局部痉挛缺血）
  - 暗黑 → 慢性淤滞、色素沉着（痹证日久）
  - 黄赤 → 充血、炎症（热证）
  - 苍白 → 血管收缩、贫血（寒证）
  - 这个经验观察与病理生理学是吻合的。
- ⚠️ **注意**：络脉望诊只能作为辅助参考，绝不能替代现代检查。出现关节疼痛、骨骼变形，必须做 X 光、血沉、CRP、类风湿因子等检查，以排除类风湿关节炎、痛风、骨肿瘤等。
- **"寒多则筋挛骨痛，热多则骨消筋缓"**：对应现代的两种病理状态——寒证（缺血、痉挛、纤维化）表现为拘急疼痛；热证（炎症、骨质疏松、肌肉萎缩）表现为痿软无力。

【卷中】十二经是动所生之病

【说明】以下十二篇是《灵枢·经脉》的核心内容。"是动病"指本经经气发生异常变动时所产生的病症；"所生病"指本经所属脏腑及循行部位所产生的病症。原文中手阳明大肠经的内容附在手太阳小肠经篇内，译文已分出单列。

◆ 一、手太阴肺之经

【原文】
是动病（气）：肺胀满，膨膨而喘咳，缺盆中痛，甚则交两手而瞀，是谓臂厥。主肺。
所生病（血）：咳嗽上气，喘喝，烦心，胸满，臑臂内前廉痛，掌中热。气盛有余则肩背痛风，汗出中风，小便数而欠；气虚则肩背痛寒，少气不足以息，溺色变，卒遗失无度。

【白话】
**是动病（属气分）**：肺部胀满，气喘咳嗽时胸部发出"膨膨"的声音，锁骨上窝（缺盆）中间疼痛，严重的会两手交叉按着胸口、视物昏花（瞀），这叫做"臂厥"（臂部气血逆乱所致的厥证）。本经**主肺**。

**所生病（属血分）**：咳嗽、气上逆，喘息有声（喘喝），心中烦闷，胸部胀满，上臂与前臂内侧前缘（桡侧）疼痛，掌心发热。
- **气盛有余**：肩背疼痛（痛风，此处指痛如风袭）、出汗、易中风邪、小便频数而量少（欠）；
- **气虚不足**：肩背部疼痛发凉，气短不足以维持正常呼吸，小便颜色改变，突然遗尿或失禁无度。

【译注】
- **缺盆**：锁骨上窝（胸骨上窝两侧的凹陷处），是肺经循行部位，也是古人诊察肺病之处。
- **瞀（mào）**：视物昏花、神志昏乱。肺经严重病变时出现，现代看可能与严重缺氧（呼吸衰竭）有关。
- **臂厥**：肺经循行于臂内侧前缘，经气逆乱导致臂部厥冷、麻木、疼痛。
- **"小便数而欠"**：肺为水之上源，主通调水道。肺气壅实则水道不利，故小便频急而量少；肺气虚则膀胱失约，故遗尿失禁。**这是中医"肺主通调水道"理论的具体体现**，说明古人已认识到呼吸系统与泌尿系统之间存在功能联系（现代研究证实：胸内压变化、血氧与二氧化碳分压确实影响肾血流与尿量）。
- **现代对应**：肺经证候群大致对应呼吸系统疾病（支气管炎、哮喘、肺炎、COPD）及其伴随症状，如胸闷、咳嗽、肩背痛、手臂内侧放射痛。

◆ 二、手阳明大肠之经

【原文】
是动病：齿痛，䪼肿。主津。
所生病：目黄，口干，鼽衄，喉痹，肩前臑痛，大指次指痛不用。气有余则当脉所过者热肿，虚则寒栗不复。

【白话】
**是动病**：牙痛，目下颧部（䪼）肿胀。本经**主津液**。

**所生病**：眼睛发黄，口干，鼻塞流涕与鼻出血（鼽衄），咽喉肿痛闭塞（喉痹），肩前部与上臂疼痛，大拇指和食指（次指）疼痛不能活动。
- **气有余（实证）**：本经脉循行经过的部位会出现发热红肿；
- **气虚（虚证）**：会出现寒冷战栗而久久不能回温（寒栗不复）。

【译注】
- **䪼（zhuō）**：眼眶下方、颧骨内侧的部位。大肠经的支脉从缺盆上颈贯颊，入下齿，还出挟口，交人中，上挟鼻孔——所以牙痛、面颊肿是大肠经的典型证候。
- **"主津"**：大肠主传导糟粕并吸收水分（"大肠主津"），与小肠"主液"相对。大肠经病变会影响津液代谢，故出现口干、目黄等燥热表现。
- **鼽（qiú）衄（nǜ）**：鼽是鼻塞流清涕，衄是鼻出血。大肠经上挟鼻孔，故鼻症归属此经。
- **"虚则寒栗不复"**：虚证见寒战，是阳气不能温煦的表现。现代看，严重感染性休克前期、甲状腺功能减退、贫血都可出现寒战畏冷。
- **现代对应**：大肠经证候群对应口腔（牙痛）、鼻（鼻炎、鼻出血）、咽喉（扁桃体炎、咽炎）、肩臂（肩周炎、网球肘）等部位疾病。这条经的穴位（尤其合谷、曲池）是头面口鼻疾病的要穴。

◆ 三、手太阳小肠经

【原文】
是动病：嗌痛，颔肿，不可回顾，肩似拔，臑似折。主腋。
所生病：耳聋，目黄，颊颔肿，颈肩臑肘臂外后廉痛。

【白话】
**是动病**：咽喉疼痛，下颌部（颔）肿胀，脖子不能向后回顾，肩膀像被人往外拉扯一样（肩似拔），上臂像折断一样疼痛（臑似折）。本经**主腋部**。

**所生病**：耳聋，眼睛发黄，面颊与下颌肿胀，颈部、肩部、上臂、肘部、前臂外侧后缘（尺侧）疼痛。

【译注】
- **嗌（yì）**：咽喉部。小肠经循咽下膈，故咽喉痛属此经。
- **肩似拔、臑似折**：这是对肩臂疼痛最形象的描述——肩部如被牵扯拔拽、上臂如被折断。现代看，这正是**神经根型颈椎病**或**肩周炎**的典型表现（疼痛沿臂后外侧放射）。古人用比喻描述，非常准确。
- **小肠经循行**：起于小指外侧→沿手背尺侧→前臂后缘→肘内两骨间→上臂后侧→肩关节后→绕肩胛→交肩上→入缺盆→络心→循咽→下膈→抵胃→属小肠。支脉从缺盆循颈上颊→至目锐眦→入耳中。所以耳聋、目黄、颊肿都归此经。
- **现代对应**：小肠经证候群对应颈椎病、肩周炎、落枕、耳鸣耳聋、腮腺炎等。

◆ 四、足厥阴肝之经

【原文】
是动病：腰痛不可以俯仰，丈夫㿉疝，妇人少腹肿，甚则嗌干，面尘脱色。主肝。
所生病：胸满，呕逆，洞泄，狐疝，遗溺，闭癃。

【白话】
**是动病**：腰痛得不能前俯后仰；男子患"㿉疝"（阴囊肿大下坠的疝气）；妇人小腹（少腹）肿胀；严重的会出现咽喉干燥、面色晦暗如蒙尘土、失去光泽（面尘脱色）。本经**主肝**。

**所生病**：胸部胀满，呕吐呃逆，泄泻完谷不化（洞泄），"狐疝"（时上时下、卧则入腹立则出腹的疝气），遗尿，小便不通（闭癃）。

【译注】
- **㿉（tuí）疝**：阴囊肿大下坠坚硬如石或麻木不知痛痒的疝气，即现代所称的腹股沟疝、阴囊疝。
- **狐疝**：疝气的一种，特点是时上时下、卧则回纳、起立则脱出，"如狐之出没无常"，故名。相当于现代的**可复性腹股沟斜疝**。古人已详细区分了疝的类型，是很有价值的外科观察。
- **面尘脱色**：面色晦暗无光，像蒙了一层灰。这是慢性肝病的典型面容——现代称**肝病面容**（面色晦暗、色素沉着），常见于肝硬化、慢性肝炎。古人这个描述非常准确。
- **闭癃**：小便不通。闭指完全不通，癃指点滴而出、排尿不畅。肝经绕阴器、抵小腹，故泌尿与生殖系统病症归此经。
- **现代对应**：肝经证候群对应肝胆疾病、泌尿生殖系统疾病、疝气、妇科少腹肿块（子宫肌瘤、卵巢囊肿）、腰痛等。

◆ 五、足少阳胆之经

【原文】
是动病：口苦，善太息，心胁痛不能转侧，甚则面微尘，体无膏泽，足外反热，是为阳厥。主骨。
所生病：头痛，角颔肿痛，目锐眦痛，缺盆中肿痛，腋下肿，马刀挟瘿，汗出振寒疟，胸胁肋髀膝外至胫绝骨外踝前及诸节皆痛，小指次指不用。

【白话】
**是动病**：口发苦，常常叹息（善太息），心窝与胁肋疼痛、身体不能转侧；严重的会出现面色微暗如蒙灰尘、皮肤失去润泽（体无膏泽）、足部外侧反而发热，这叫做"阳厥"（少阳阳气厥逆）。本经**主骨**。

**所生病**：头痛，额角（角）与下颌（颔）肿痛，外眼角（目锐眦）疼痛，锁骨上窝（缺盆）中肿痛，腋下肿胀，"马刀挟瘿"（腋下与颈部淋巴结肿大），出汗、寒战发抖、疟疾，胸胁肋部、大腿（髀）、膝外侧一直到小腿（胫）、绝骨（外踝上）、外踝前方以及各个关节都疼痛，足第四趾（小指次指）不能活动。

【译注】
- **口苦、善太息**：这是少阳病（胆病）最典型的两个症状。口苦是胆汁反流所致（现代证实胆道疾病、胃食管反流可致口苦）；善太息（长叹气）是情志抑郁、气机不畅的表现。二者并见，古人谓之"胆郁"。
- **马刀挟瘿**：古病名。"马刀"是腋下淋巴结肿大到形如马刀；"挟瘿"是颈部（瘿，即颈前颔下）淋巴结结核。现代看，这就是**颈部与腋下淋巴结结核（瘰疬）**，由结核杆菌感染引起。在抗生素发明之前，这是常见病。胆经循行经过腋下、颈侧，故归此经。
- **体无膏泽**：皮肤干燥失去光泽。胆为"中正之官"，胆汁分泌障碍（黄疸、胆道梗阻）会导致皮肤干燥、瘙痒、色泽改变。
- **"足外反热"**：足外侧发热，而身体其他部位可能畏寒。这是少阳病"寒热往来"特点的表现之一。
- **主骨**：胆经主骨，是《灵枢》的特殊理论（"少阳为枢……主骨所生病"）。现代看，胆经循行经过髋、膝、踝等大关节，与骨骼关节关系密切。
- **现代对应**：胆经证候群对应偏头痛、胆囊炎胆石症、颈淋巴结核、坐骨神经痛（沿下肢外侧放射）、肋间神经痛、带状疱疹等。**胆经是治疗偏头痛与坐骨神经痛最重要的经脉。**

◆ 六、足少阴肾之经

【原文】
是动病：饥不欲食，面黑如炭色，咳唾则有血，喉鸣而喘，坐而欲起，目䀮䀮无所见，心悬若饥状，气不足则善恐，心惕惕若人将捕之，是谓骨厥。主肾。
所生病：口热，舌干，咽肿，上气，嗌干及痛，烦心，心痛，黄疸，肠澼，脊股内后廉痛，痿厥，嗜卧，足下热而痛。

【白话】
**是动病**：感觉到饥饿却不想吃东西；面色发黑像木炭一样（面黑如炭色）；咳嗽、吐唾沫时带血；喉咙发出鸣响、气喘；坐着总想站起来（坐而欲起，心神不宁的表现）；眼睛昏花视物不清（目䀮䀮无所见）；心里像悬着一样空落落的，像饥饿时的感觉（心悬若饥状）；气不足就容易恐惧，心中怵惕不安，好像有人要来抓捕自己；这叫做"骨厥"（肾主骨，肾气厥逆）。本经**主肾**。

**所生病**：口中发热，舌头发干，咽喉肿，气上逆，咽喉干燥作痛，心中烦闷，心痛，黄疸，痢疾（肠澼），脊柱与大腿内侧后缘疼痛，肢体痿软厥冷，嗜睡，脚底发热而疼痛。

【译注】
- **面黑如炭色**：这是慢性肾病（尿毒症）的典型体征——**肾性面容**（面色晦暗黧黑，因尿素等代谢产物沉积与贫血所致）。古人的观察十分准确。
- **饥不欲食**：肾阴不足、虚火扰胃的表现。现代看，慢性肾病、尿毒症患者常有恶心、食欲不振（尿毒症毒素刺激胃肠道）。
- **咳唾有血、喉鸣而喘**：肾经"其直者，从肾上贯肝膈，入肺中，循喉咙，挟舌本"，故肾病可影响肺。现代看，**尿毒症性肺水肿**、**肾性高血压致左心衰**都可出现咳血、喘息。
- **心悬若饥状、善恐、心惕惕若人将捕之**：这组症状描述的是**严重的焦虑状态**。中医认为"肾在志为恐"，肾虚则善恐。现代看，慢性肾病、甲状腺功能亢进、焦虑症都可出现。这段描写是中医心理学的经典文本，把"惊恐发作"刻画得极为生动。
- **骨厥**：肾主骨，肾气厥逆则骨失所养，故名。现代看，肾性骨病（肾性骨营养不良）确实是慢性肾病的常见并发症。
- **足下热而痛**：肾经起于足小趾下、斜走足心（涌泉穴）。足底发热疼痛，是肾阴不足、虚火下注的表现。现代可见于足底筋膜炎、周围神经病变。
- **肠澼**：指痢疾或便下脓血的疾病。

◆ 七、手少阴心之经

【原文】
是动病：嗌干，心痛，渴而欲饮，是谓臂厥。主心。
所生病：目黄，胁痛，臑臂内后廉痛，厥，掌中热。

【白话】
**是动病**：咽喉干燥，心痛，口渴想喝水，这叫做"臂厥"。本经**主心**。

**所生病**：眼睛发黄，胁肋疼痛，上臂与前臂内侧后缘疼痛，四肢厥冷，掌心发热。

【译注】
- **嗌干、心痛、渴而欲饮**：心经的三个主症。现代看，这组症状高度提示**心血管疾病**——心绞痛、心肌梗死发作时常伴有口干、烦躁、口渴（交感神经兴奋、出汗脱水所致）。古人把"心痛"与"渴"并提，是有临床依据的。
- **臂厥**：心经循行于臂内侧后缘（尺侧），经气逆乱则臂部厥冷疼痛。⚠️ **重要提示**：**左侧手臂内侧放射痛是心绞痛/心肌梗死的典型表现**（牵涉痛），古人称之为"臂厥"，与现代医学的认识一致。凡是突然出现胸痛伴左臂内侧放射、冷汗、濒死感的，**必须立即呼叫急救（120），这是分秒必争的急症**。
- **目黄**：心经有热可致目黄。现代看，"目黄"（巩膜黄染）是黄疸的表现，与肝胆疾病相关。心经目黄可能指心源性黄疸（严重心衰致肝淤血）。

◆ 八、手厥阴心包络经

【原文】
是动病：手心热，肘臂挛急，腋肿，甚则胸胁支满，心中澹澹大动，面赤，目黄，善笑不休。主脉。
所生病：烦心，心痛，掌中热。

【白话】
**是动病**：手心发热，肘部与手臂拘挛紧急，腋下肿胀；严重的会出现胸胁部撑胀满闷，心中悸动不安、跳动剧烈（心中澹澹大动），面色发红，眼睛发黄，不停地笑（善笑不休）。本经**主脉**。

**所生病**：心中烦闷，心痛，掌心发热。

【译注】
- **心中澹澹大动**：形容心脏剧烈跳动、悸动不安的样子。"澹澹"是水波摇动的样子，用来形容心悸非常形象。现代对应**心悸、心律失常**（房颤、早搏、心动过速）。
- **善笑不休**：心在志为喜，心气实则喜笑不止。这是中医情志病理论的表述。现代看，持续性无法自控的笑可见于**假性延髓情绪（PBA）**、某些额叶病变、精神疾病。古人把它归为心包经实证。
- **心包络**：即心包，是包裹心脏的膜囊。中医认为"心为君主之官，不受邪"，外邪犯心时由心包代受，故心包的病证多与心的实证（热、痰、瘀）相关，而心经多主虚证。这是很有临床意义的区分：**清热开窍（如中暑昏迷、高热神昏）取心包经穴（中冲、劳宫）；补养心血取心经穴（神门、少冲）**。
- **主脉**：心主血脉，心包代心行事，故亦主脉。

◆ 九、足太阳膀胱经

【原文】
是动病：头痛，目似脱，项似拔，脊痛，腰似折，髀不可以曲，腘如结，腨如裂，是谓踝厥。主筋。
所生病：痔，疟，狂癫疾，头脑顶痛，目黄，泪出，鼽衄，项背腰尻腘腨脚皆痛，小指不用。

【白话】
**是动病**：头痛，眼睛像要脱出来一样胀痛（目似脱），脖子像被拔扯一样强痛（项似拔），脊柱疼痛，腰部像折断一样痛（腰似折），大腿（髀）不能弯曲，膝腘窝像打了结一样拘紧（腘如结），小腿肚（腨）像裂开一样疼痛（腨如裂），这叫做"踝厥"。本经**主筋**。

**所生病**：痔疮，疟疾，狂证与癫证（精神病），头顶部疼痛，眼睛发黄，流泪，鼻塞流涕与鼻出血，颈项、背部、腰部、尾骶（尻）、膝腘窝、小腿、脚都疼痛，足小趾不能活动。

【译注】
- **"目似脱、项似拔、腰似折、腘如结、腨如裂"**：这一串比喻是全篇最精彩的描述，精准刻画了**急性腰腿痛**的表现。现代看，这正是**腰椎间盘突出症急性发作、坐骨神经痛**的典型症状：腰部剧痛如折、脊柱强直、大腿不能屈曲、腘窝与小腿肚剧烈放射痛。古人用五个比喻把一组症状群描述得极为生动，说明当时对坐骨神经痛的认识已经相当成熟。
- **踝厥**：膀胱经循行经过外踝后方（昆仑穴），经气厥逆则踝部上下厥冷疼痛。
- **主筋**：膀胱经为"巨阳"，主一身之表，与筋（肌腱韧带）关系密切。现代看，膀胱经循行路线（后正中线两侧）与**竖脊肌、臀大肌、股二头肌、腓肠肌**等肌群的走向高度吻合——这条经脉实质上反映了人体后侧肌筋膜链（现代解剖学的"后表线"）。
- **痔**：膀胱经的支脉从腰中下挟脊、贯臀、入腘中，与肛门关系密切。现代针灸治痔常用膀胱经的**承山、秩边、会阳**等穴，确有疗效。
- **狂癫疾**：膀胱经"其直者，从巅入络脑"，故与精神神志病相关。现代针灸治疗精神疾病常取头部膀胱经穴（如攒竹、天柱、五脏六腑背俞穴）。

◆ 十、足阳明胃之经

【原文】
是动病：凄凄然振寒，善伸数欠，颜黑，病至则恶人与火，闻木音则惕然而惊，心动，欲闭户牖而独处，甚则欲上高而歌，弃衣而走，贲响腹胀，是谓骭厥。主血。
所生病：狂疟，温淫汗出，鼽衄，口㖞唇胗，颈肿喉痹，大腹水肿，膝膑肿痛，循膺乳、街、股、伏兔、胻外廉、足跗上皆痛，中指不用。气盛则身已前皆热，其有余于胃则消谷善饥，溺色黄；气不足则身已前皆寒栗，胃中寒则胀满。

【白话】
**是动病**：瑟瑟发抖地怕冷（凄凄然振寒），常常伸懒腰、打哈欠（善伸数欠），额部（颜）发黑；病发作时厌恶见人与火光，听到木头敲击的声音就惊恐不安、心跳加速，想要关上门窗独自待着；严重的会想爬到高处唱歌、脱掉衣服乱跑（弃衣而走），腹中气机奔响、腹部胀满，这叫做"骭厥"（骭即小腿骨，指经气自胫部上逆）。本经**主血**。

**所生病**：疟疾发狂，温热病大汗出，鼻塞流涕与鼻出血，口角歪斜（口㖞）、唇生疮疹（唇胗），颈部肿大、咽喉闭塞，大腹水肿，膝盖（膑）肿痛，沿着胸膺部、乳房、气街（腹股沟）、大腿、伏兔（大腿前）、小腿外侧、足背都疼痛，足中趾不能活动。
- **气盛**：身体前面（胸腹部）都发热；胃气有余则消化快、容易饥饿（消谷善饥）、小便发黄；
- **气不足**：身体前面都发冷战栗；胃中有寒则腹部胀满。

【译注】
- **"恶人与火，闻木音则惊，欲闭户牖而独处，欲上高而歌，弃衣而走"**：这是《内经》中**最著名的一段精神病描写**，后世称之为"阳明病发狂"。这些症状（怕光、怕声响、社交退缩、登高而歌、脱衣奔跑、躁动不安）现代看属于**躁狂发作、精神分裂症急性期、谵妄状态**。古人把它归入阳明胃经，是因为这类病症常伴**大便燥结、腹满、口渴**等胃肠实热症状——现代医学也证实，严重便秘、肠梗阻、肝性脑病等躯体疾病确实可以引发精神症状（**躯体疾病所致精神障碍**）。中医用通腑泻热（大承气汤）治疗这类狂证，是有物质基础的：解除肠道梗阻与毒素吸收后，精神症状随之缓解。**这是中医"胃肠—大脑轴"思想的雏形，比现代"肠脑轴"（gut-brain axis）研究早了两千年。**
- **消谷善饥、溺色黄**：这是**糖尿病（消渴）**或**甲状腺功能亢进**的典型表现——吃得多、容易饿、小便黄。古人归入胃热，与现代内分泌学的认识方向一致。
- **身以前皆热 / 皆寒栗**：胃经循行于人体前面（胸腹、下肢前侧），所以身体前面的寒热变化反映胃经气血盛衰。这个观察很直观。
- **主血**：阳明多血多气，故主血。这也是为什么阳明经穴可以放血、深刺。
- **伏兔**：大腿前侧股四头肌隆起处（髂前上棘与髌骨外缘连线上约 6 寸），形如趴伏的兔子，故名。
- **胻（héng）**：小腿胫骨，此处指小腿外侧。

◆ 十一、手少阳三焦经

【原文】
是动病：耳聋，浑浑焞焞，嗌肿喉痹。主气。
所生病：汗出，目锐眦痛，耳后、肩、臑、肘、臂外皆痛，小指次指不用。

【白话】
**是动病**：耳聋，听觉浑浊不清、轰轰作响（浑浑焞焞），咽喉肿胀、闭塞。本经**主气**。

**所生病**：出汗，外眼角（目锐眦）疼痛，耳后、肩部、上臂、肘部、前臂外侧都疼痛，无名指（小指次指）不能活动。

【译注】
- **浑浑焞焞（tūn）**：形容耳鸣耳聋时听觉模糊、声音轰隆不清的状态。这是**耳鸣**最形象的古汉语描述。三焦经"其支者，从耳后入耳中，出走耳前"，故耳鸣耳聋为三焦经主症。
- **"主气"**：三焦是"元气之别使"，主持诸气、总司全身气机与水液代谢。所以三焦经的病症多与气机、水液相关（汗出、水肿、耳鸣）。
- **现代对应**：三焦经证候群对应耳鸣耳聋（突发性耳聋、梅尼埃病）、偏头痛（耳后、颞部）、肩臂外侧疼痛（网球肘、桡神经痛）、汗出异常（植物神经功能紊乱）。**三焦经是治疗耳鸣与偏头痛的要经。**

◆ 十二、足太阴脾之经

【原文】
是动病：舌本强，食则呕，胃脘痛，腹胀，善噫，得后与气则快然如衰，身体皆重。主脾。
所生病：舌本痛，体不能动摇，食不下，烦心，心下急痛，寒疟，溏瘕泄，水闭，黄疸，不能卧，强立，股膝内肿厥，足大指不用。

【白话】
**是动病**：舌根（舌本）强硬不灵活，一吃东西就呕吐，胃脘疼痛，腹部胀满，常常嗳气（善噫），**大便后或排气后就觉得轻快许多，好像病去了一大半**（得后与气则快然如衰），全身沉重。本经**主脾**。

**所生病**：舌根疼痛，身体不能转侧动摇，食物咽不下，心中烦闷，心下（胃脘部）急迫疼痛，寒性疟疾，大便溏泄夹有痞块（溏瘕泄），水液闭阻（水闭，指水肿、小便不利），黄疸，不能平卧，勉强站立，大腿与膝部内侧肿痛厥冷，足大趾不能活动。

【译注】
- **"得后与气则快然如衰"**：这是脾虚气滞最典型的诊断要点——腹胀、嗳气，**排便或排气后症状明显缓解**。现代看，这正是**肠易激综合征（IBS）、功能性消化不良**的典型表现。古人用一句话就抓住了功能性胃肠病的核心特征，极为精准。
- **舌本强**：舌根僵硬、言语不清。脾经"上膈，挟咽，连舌本，散舌下"，故舌症归脾。现代看，舌强可见于脑血管意外（中风失语）、舌肌麻痹。
- **溏瘕泄**：大便稀溏且夹有不消化物或结块。对应现代的慢性腹泻、吸收不良综合征。
- **水闭**：水液代谢障碍，可指水肿或小便不利。脾主运化水湿，脾虚则水停。
- **身重**：全身沉重乏力。这是脾虚湿困的典型表现，现代可见于低钾血症、甲状腺功能减退、慢性疲劳综合征。
- **现代对应**：脾经证候群对应消化系统疾病（胃炎、肠炎、消化不良、IBS）、水肿、黄疸、糖尿病、妇科出血性疾病（脾统血）。

【卷下】十二经穴治证

【说明】以下按经脉列举四肢肘膝以下的**五输穴**（井、荥、俞、经、合）与**原穴**。每项依次说明：五行属性 → 定位 → 经气类别（井/荥/俞/经/合/原）→ 主治 → 刺灸法。

【五输穴速查】

| 名称 | 经气特性 | 比喻 | 主治特点 |
|---|---|---|---|
| **井** | 经气初出 | 水的源头 | 急救、醒神、治心下满 |
| **荥** | 经气稍盛 | 小水流 | 清热、治身热 |
| **俞** | 经气灌注转输 | 水流汇聚 | 治体重节痛、关节病 |
| **经** | 经气盛大流通 | 江河畅通 | 治喘咳寒热、咽喉病 |
| **合** | 经气汇合入脏 | 百川入海 | 治脏腑病、逆气而泄 |
| **原** | 原气经过留止 | — | 治本经所属脏腑病 |

◆ 一、手太阴肺经（五穴）

**【经脉概要】**起于中焦（胃脘），下络大肠，还循胃口，上膈属肺，从肺系横出腋下，沿上臂内侧前缘下行，入寸口，上鱼际，出拇指端。支脉从腕后（列缺）分出，走向食指内侧端，接大肠经。
**【穴序】**少商（井）— 鱼际（荥）— 太渊（俞）— 经渠（经）— 尺泽（合）

───────────────

**○ 少商（井，属木）**
【定位】在手大拇指末端内侧（桡侧），距指甲角约一分（如韭菜叶宽）处。
【经气】手太阴肺经脉气所出，为井穴。
【主治】心中烦闷、频繁呃逆（善哕）、心下胀满、汗出而恶寒、咳嗽气逆、疟疾、寒战发抖、腹部胀满、口中唾沫多、嘴唇干燥、想喝水却咽不下、胸部膨膨胀满、手指拘挛疼痛、寒战、牙关打颤（鼓颔）、喉中作响。
【刺灸法】用三棱针点刺，微出血，以泄五脏之热。（⚠️ 古代医案：唐代刺史成君绰忽然腮颔肿大如升、喉中闭塞、水米不下三日，甄权针刺少商，立刻痊愈。）**不宜灸**。
【译注】少商是**急救要穴**，现代用于急性咽喉肿痛（扁桃体炎、急性咽炎）、昏迷急救。点刺出血能迅速缓解咽喉部充血水肿。⚠️ 必须由医师操作，注意消毒；有出血倾向者禁用。
（原文"凑唐刺史成君绰"中的"凑"字疑为衍文或传抄之误，译文按文义调整为"古代医案"。）

───────────────

**○ 鱼际（荥，属火）**
【定位】在手大拇指本节（第一掌指关节）后内侧，掌面赤白肉际（手掌与手背皮肤交界）处，当第一掌骨中点桡侧。
【经气】手太阴肺脉气所流注，为荥穴。
【主治】酒病（饮酒过度所致病症）、恶风寒、虚热、舌苔发黄、身热、头痛、咳嗽、汗不出、痹痛走窜胸背、痛而不得喘息、目眩、心烦、气短、腹痛、吃不进食、肘部拘挛、四肢胀满、喉中干燥、寒战牙颤、咳嗽牵引尾骶痛、小便失禁、呕血、心痹（心脏痹阻）、悲伤恐惧。
【刺灸法】针入二分，留针三呼（约数秒）。
【译注】鱼际是**清热利咽要穴**，现代常用于咽喉炎、扁桃体炎、支气管炎、发热。孕妇慎用。

───────────────

**○ 太渊（俞，属土）**
【定位】在手腕掌侧横纹桡侧凹陷中（桡动脉搏动处）。
【经气】手太阴肺脉气所灌注，为俞穴；又为**八会穴之一（脉会太渊）**。
【主治】胸痹、气逆、寒厥、频繁呃逆、呕吐清水、咳嗽、烦闷不得卧、肺部胀满膨膨、臂内侧疼痛、目生白翳（角膜白斑）、眼眦赤筋、锁骨上窝牵引痛、掌心发热、频频呵欠、喘息不得平息、嗳气上逆、心痛、呕血、寒战、咽干、狂言、口㖞。
【刺灸法】可灸三壮，针入二分。
【译注】太渊是**肺经原穴**（阴经以俞代原），也是"脉会"，凡血脉病（无脉症、脉管炎、心律不齐）都可取用。⚠️ 此处有桡动脉，针刺须避开血管，由医师操作。

───────────────

**○ 经渠（经，属金）**
【定位】在寸口（桡动脉）陷中，腕横纹上 1 寸，桡骨茎突与桡动脉之间。
【经气】手太阴肺脉气所经过，为经穴。
【主治】疟疾寒热、胸背拘急、胸部胀满膨膨、喉痹、掌心发热、咳嗽气逆、频繁呵欠、热病汗不出、突然发生的痹证、喘息急促、心痛、呕吐。
【刺灸法】针入二分，留针三呼。**禁灸**——灸则损伤人的神气（因穴位正当动脉，灸易致血管损伤）。
【译注】"禁不可灸"是古人重要的安全提示：动脉浅表处不可施灸，否则可致血管损伤、出血。这个禁忌现代仍然遵守。

───────────────

**○ 尺泽（合，属水）**
【定位】在肘窝横纹中央，肱二头肌腱桡侧凹陷中（肘关节微屈时肘横纹上动脉处）。
【经气】手太阴肺脉气所汇入，为合穴。
【主治】风痹、肘部拘挛、手臂不能上举、喉痹、气上逆、口干、咳嗽、咳吐浊痰、四肢突然浮肿、臂部发凉、气短。
【刺灸法】针入三分，可灸五壮。
【译注】尺泽是**肺经合穴**，"合治内腑"，善治肺系实热证（急性支气管炎、肺炎、咯血）。现代常用尺泽点刺放血治急性咽炎、中暑。⚠️ 此处有肘正中静脉，放血须严格消毒。

◆ 二、手阳明大肠经（六穴）

**【经脉概要】**起于食指末端（商阳），沿食指桡侧上行，经第一、二掌骨间（合谷），入腕（阳溪），沿前臂外侧前缘上行，经肘外（曲池），上臂外侧前缘，至肩（肩髃），交会大椎，下入缺盆，络肺，下膈属大肠。支脉从缺盆上颈贯颊，入下齿，还出挟口，交人中，上挟鼻孔。
**【穴序】**商阳（井）— 二间（荥）— 三间（俞）— 合谷（原）— 阳溪（经）— 曲池（合）

───────────────

**○ 商阳（井，属金）**，一名绝阳
【定位】在食指末端内侧（桡侧），距指甲角约一分处。
【经气】手阳明大肠脉气所出，为井穴。
【主治】胸中气满、气喘咳嗽、四肢肿胀、热病汗不出、耳鸣耳聋、寒热往来、疟疾、口干、下颌部肿、牙痛、恶寒、肩背拘急相互牵引作痛、锁骨上窝痛、目青盲（视力减退）。
【刺灸法】可灸三壮。**右病取左，左病取右**（缪刺法）。针入一分，留针一呼。（原文"如顷食立已"，意为针刺后不久即可进食，指咽喉肿痛者针后即能吞咽。）
【译注】缪刺（交叉取穴）是《内经》的重要针法，左侧病取右侧穴，反之亦然。现代研究显示这与脊髓对侧传导通路有关。

───────────────

**○ 二间（荥，属水）**，一名间谷
【定位】微握拳，在食指本节（第二掌指关节）前缘桡侧凹陷中。
【经气】手阳明大肠脉气所流注，为荥穴。
【主治】喉痹、下颌肿、肩背痛、寒战、鼻塞流涕与鼻出血、易受惊、口㖞。
【刺灸法】针入三分，可灸三壮。

───────────────

**○ 三间（俞，属木）**，一名少谷
【定位】微握拳，在食指本节（第二掌指关节）后缘桡侧凹陷中。
【经气】手阳明大肠脉气所灌注，为俞穴。
【主治】喉痹、咽喉中如有物梗塞（咽中如梗）、龋齿牙痛、嗜睡、胸部胀满、肠鸣、洞泄（水样腹泻）、寒疟、嘴唇焦干、口干、气喘、目眦拘急疼痛。
【刺灸法】针入三分，留针三呼，可灸三壮。

───────────────

**○ 合谷（原穴）**，一名虎口
【定位】在手背第一、二掌骨之间，约当第二掌骨桡侧中点处（简便取穴：一手拇指指间关节横纹对准另一手虎口边缘，拇指尖按下处即是）。
【经气】手阳明大肠脉气所经过，为原穴。
【主治】寒热往来、疟疾、鼻塞流涕与鼻出血、热病汗不出、视物不明、头痛、龋齿牙痛、喉痹、手臂痿软、面部浮肿、口唇不能收合、失音不能言语、牙关紧闭不能张开。
【刺灸法】针入三分，留针六呼，可灸三壮。
⚠️ **重要禁忌**：**孕妇不可针刺合谷**——针之可损动胎气。
【译注】
- 合谷是**针灸第一大穴**，有"面口合谷收"之说——头面部、口齿咽喉疾病都取合谷。现代研究证实针刺合谷有显著的镇痛作用（激活内源性阿片肽系统），广泛用于头痛、牙痛、术后镇痛。
- ⚠️ **孕妇禁针**：合谷有明显的活血通经、兴奋子宫作用，孕期（尤其有流产史者）列为禁忌。这是中医针灸最著名的禁忌之一，现代针灸学仍然遵守。合谷与三阴交并称"孕妇禁针两穴"。

───────────────

**○ 阳溪（经，属火）**，一名中魁
【定位】在腕背横纹桡侧，拇短伸肌腱与拇长伸肌腱之间的凹陷中（拇指上翘时两筋间凹陷处）。
【经气】手阳明大肠脉气所经过，为经穴。
【主治】狂言、喜笑、幻觉见鬼、热病心烦、眼目受风赤烂、有翳膜、四肢厥逆、头痛、胸部胀满不得喘息、寒热往来、疟疾、喉痹、耳鸣、牙痛、惊风抽搐（惊制）、肘臂不能上举、痂疥（皮肤疮癣）。
【刺灸法】针入三分，留针七呼，可灸三壮。

───────────────

**○ 曲池（合，属土）**
【定位】屈肘成直角，在肘横纹外侧端与肱骨外上髁连线中点凹陷处。
【经气】手阳明大肠脉气所汇入，为合穴。
【主治】肘中疼痛、偏风半身不遂、刺风瘾疹（荨麻疹）、喉痹不能言语、胸中烦满、筋脉弛缓握物无力、挽弓不开、屈伸困难、风痹、肘部细瘦无力、伤寒余热不尽、皮肤干燥。
【刺灸法】针入七分，得气后**先泻后补**；灸效果也很好，可灸三壮。
【译注】曲池是**清热要穴**，善治皮肤病（荨麻疹、湿疹、痤疮）、发热、高血压、肩肘关节病。现代研究证实针刺曲池有降压、抗炎、抗过敏作用。⚠️ 原文"针入七分"较深，现代一般用 1.0–1.5 寸（约 25–40 mm），视患者胖瘦而定。

◆ 三、手少阴心经（五穴）

**【经脉概要】**起于心中，出属心系（心与其他脏腑相连的脉络），下膈络小肠。支脉从心系上挟咽，系目系。直行者从心系上肺，出腋下（极泉），沿上臂内侧后缘，行于太阴、厥阴之后，下肘内（少海），沿前臂内侧后缘至掌后（神门），入掌内后廉，出小指端（少冲）。
**【穴序】**少冲（井）— 少府（荥）— 神门（俞）— 灵道（经）— 少海（合）

───────────────

**○ 少冲（井，属木）**，一名经始
【定位】在手小指末端内侧（桡侧），距指甲角约一分处。
【经气】手少阴心脉气所出，为井穴。
【主治】热病烦闷、气上逆、心痛、痰饮内冷、气短、悲伤恐惧易惊、掌心发热、胸中疼痛、口中发热、咽喉发酸、忽冷忽热、手指拘挛不能伸展、牵引肘腋疼痛。
【刺灸法】针入一分，可灸三壮。
【译注】少冲是**醒神开窍要穴**，现代用于中暑昏迷、休克急救、心悸。点刺出血可泄心火。

───────────────

**○ 少府（荥，属火）**
【定位】在手掌第四、五掌骨之间，握拳时小指尖所指处（约当劳宫穴的对侧）。
【经气】手少阴心脉气所流注，为荥穴。
【主治】烦闷、气短、悲伤恐惧怕见人、掌心发热、肘腋拘挛紧急、胸中疼痛、手蜷屈不能伸展。
【刺灸法】针入二分，可灸七壮。

───────────────

**○ 神门（俞，属土）**，一名兑冲
【定位】在腕部掌侧横纹尺侧端，尺侧腕屈肌腱的桡侧凹陷中。
【经气】手少阴心脉气所灌注，为俞穴；又为**心经原穴**。
【主治】疟疾、心中烦躁（烦心得想喝冷水，恶寒时又想待在温暖处）、咽干、不想进食、心痛、频频嗳气、恐惧心悸、气短不足、手臂发凉、气喘上逆、身热、狂笑悲哭、呕血、气上逆、遗尿、大人与小儿五痫（五种癫痫）。
【刺灸法】可灸七壮（艾炷如小麦粒大），针入三分，留针七呼。
【译注】神门是**安神第一要穴**，现代广泛用于失眠、焦虑、心悸、心律不齐、更年期综合征、癫痫辅助治疗。研究证实针刺神门可调节心率变异性、改善睡眠质量。这个名字起得极好——"神"出入的门户。

───────────────

**○ 灵道（经，属金）**
【定位】在腕横纹上 1.5 寸，尺侧腕屈肌腱的桡侧缘。
【经气】手少阴心脉气所经过，为经穴。
【主治】心痛、悲伤恐惧相互牵引（悲恐相引）、抽搐（瘛疭）、肘部拘挛、突然失音不能言语。
【刺灸法】可灸三壮，针入三分。
【译注】"暴喑不能言"（突然失音）现代可见于癔症性失声、喉返神经麻痹、脑卒中后失语。古人用心经穴治失音，是因为"心开窍于舌"（实则心经循行"上挟咽"）。

───────────────

**○ 少海（合，属水）**，一名曲节
【定位】屈肘，在肘横纹内侧端与肱骨内上髁连线中点凹陷处。
【经气】手少阴心脉气所汇入，为合穴。
【主治】寒热往来、龋齿牙痛、目眩、发狂、呕吐涎沫、颈项不能回顾、肘部拘挛、腋胁下疼痛、四肢不能上举。
【刺灸法】针入三分，可灸三壮。（甄权说：屈手向头取穴，治齿寒、脑风头痛；**不宜灸**，针入五分。）
【译注】原文对少海的灸法有两说（本条言可灸三壮，甄权言不宜灸），临床以少灸或不灸为稳妥。少海现代用于肘关节病、尺神经麻痹、三叉神经痛、淋巴结肿大。

◆ 四、手太阳小肠经（六穴）

**【经脉概要】**起于小指外侧端（少泽），沿手背尺侧上行至腕（腕骨、阳谷），出尺骨茎突，沿前臂外侧后缘直上，经肘内两骨之间（小海），沿上臂外侧后缘，出肩关节，绕肩胛，交肩上，入缺盆，络心，循咽下膈，抵胃属小肠。支脉从缺盆循颈上颊，至目锐眦，入耳中。
**【穴序】**少泽（井）— 前谷（荥）— 后溪（俞）— 腕骨（原）— 阳谷（经）— 小海（合）

───────────────

**○ 少泽（井，属金）**，一名小吉
【定位】在手小指末端外侧（尺侧），距指甲角约一分处。
【经气】手太阳小肠脉气所出，为井穴。
【主治】疟疾寒热、汗不出、喉痹、舌体强硬、口干、心烦、臂痛、抽搐、咳嗽、颈项拘急不能回顾、目生翳膜遮盖瞳孔。
【刺灸法】可灸一壮，针入一分。
【译注】少泽是**通乳要穴**，现代广泛用于产后乳汁不足、乳腺炎（配合膻中、乳根）。古人虽未明说通乳，但后世针灸家极为推崇。

───────────────

**○ 前谷（荥，属水）**
【定位】微握拳，在手小指外侧（尺侧）本节（第五掌指关节）前方凹陷中。
【经气】手太阳小肠脉气所流注，为荥穴。
【主治】热病汗不出、疟疾、癫疾、耳鸣、下颌肿、喉痹、咳嗽、鼻出血、颈项疼痛、鼻塞不利、目生白翳、手臂不能上举。
【刺灸法】可灸一壮，针入**（八分，原文如此，疑为"一分"之误。此穴皮肉极薄，不可能刺入八分，今本多作"一分"）**。
【译注】这条提示电子古籍中的数字传抄错误很常见，学习时需结合解剖常识判断。

───────────────

**○ 后溪（俞，属木）**
【定位】微握拳，在手小指外侧（尺侧）本节（第五掌指关节）后方凹陷中，掌横纹尺侧尽头。
【经气】手太阳小肠脉气所灌注，为俞穴；又为**八脉交会穴之一，通督脉**。
【主治】疟疾寒热、目赤生翳、鼻出血、耳聋、胸部胀满、颈项强直不能回顾、癫疾、臂肘拘挛紧急。
【刺灸法】可灸一壮，针入一分（原文"针入一分"，今本多作"针入五分至一寸"）。
【译注】后溪是**颈项病与癫痫的要穴**，通督脉。现代用于落枕、颈椎病、急性腰扭伤、癫痫辅助治疗。古人说"颈项强痛取后溪"，至今沿用。

───────────────

**○ 腕骨（原穴）**
【定位】在手掌尺侧，第五掌骨基底与三角骨之间的凹陷中（赤白肉际）。
【经气】手太阳小肠脉气所经过，为原穴。
【主治】热病汗不出、胁下疼痛不得喘息、颈颌肿、寒热往来、耳鸣、目出冷泪、生翳膜、狂躁、偏枯（半身不遂）、臂肘不能屈伸、疟疾、头痛、烦闷、惊风抽搐、五指抽搐。
【刺灸法】可灸三壮，针入二分，留针三呼。

───────────────

**○ 阳谷（经，属火）**
【定位】在手腕尺侧，尺骨茎突与三角骨之间的凹陷中。
【经气】手太阳小肠脉气所经过，为经穴。
【主治】癫疾、狂走、热病汗不出、胁痛、颈颌肿、寒热往来、耳聋耳鸣、龋齿牙痛、臂外侧疼痛不能上举、胡言乱语、左右顾盼、抽搐、目眩。
【刺灸法】可灸三壮，针入二分，留针二呼。

───────────────

**○ 小海（合，属土）**
【定位】屈肘，在尺骨鹰嘴与肱骨内上髁之间的凹陷中（肘内侧两骨之间）。
【经气】手太阳小肠脉气所汇入，为合穴。（甄权说：屈手向头取之。）
【主治】寒热往来、齿龈肿、风眩、颈项痛、痈疡肿、寒战、肘腋肿、少腹痛、四肢不能上举。
【刺灸法】可灸三壮，针入二分。
⚠️ **注意**：此处正当**尺神经沟**（尺神经经过），针刺时若触及尺神经，会引起强烈的触电样麻感向小指放射。操作须由专业医师进行，避免损伤神经。

◆ 五、手厥阴心包络经（五穴）

**【经脉概要】**起于胸中，出属心包络，下膈，依次联络上、中、下三焦。支脉循胸出胁，下腋三寸，上抵腋下，沿上臂内侧行于太阴、少阴之间，入肘中（曲泽），下前臂两筋（桡侧腕屈肌腱与掌长肌腱）之间，入掌中（劳宫），出中指端（中冲）。支脉从掌中分出，出无名指端。
**【穴序】**中冲（井）— 劳宫（荥）— 大陵（俞）— 间使（经）— 曲泽（合）

───────────────

**○ 中冲（井，属木）**
【定位】在手中指末端中央，距指甲游离缘约一分处（一说在中指尖端）。
【经气】手厥阴心包脉气所出，为井穴。
【主治】热病烦闷、汗不出、掌心发热、全身如火灼热、心痛烦满、舌体强硬。
【刺灸法】针入一分。
【译注】中冲是**中暑、昏迷急救要穴**，点刺出血可泄心包之热。现代用于中暑、休克、心绞痛的急救。

───────────────

**○ 劳宫（荥，属火）**
【定位】在手掌心，第二、三掌骨之间偏于第三掌骨，握拳时中指尖所指处。
【经气】手厥阴心包脉气所流注，为荥穴。
【主治】中风、易怒、悲笑不止、手部痹痛、热病三日汗不出、惊恐怵惕、胸胁痛不能转侧、大小便带血、鼻出血不止、气逆呕哕、烦渴、饮食不下、大人与小儿口中有腥臭气味、胸胁支撑胀满、黄疸、目黄。
【刺灸法】可灸三壮。
【译注】劳宫是**清心火要穴**，现代用于口腔溃疡、口臭、手掌多汗症、心绞痛、焦虑症。⚠️ 原文"大小人口中腥毙"中的"毙"字疑为"气"之误，译文按"口中有腥臭气味"处理。

───────────────

**○ 大陵（俞，属土）**，（原文"太陵"）
【定位】在腕掌横纹中央，掌长肌腱与桡侧腕屈肌腱之间。
【经气】手厥阴心包脉气所灌注，为俞穴；又为**心包经原穴**。
【主治】热病汗不出、臂部拘挛、腋下肿、喜笑不止、心中空悬如有饥饿感、易悲伤哭泣、惊恐、目赤、小便带血、呕逆、狂言、心中不乐、喉痹、口干、身热、头痛、气短、胸胁痛。
【刺灸法】针入五分，可灸三壮。
【译注】⚠️ 此处有**正中神经**通过，针刺时若触及可引起麻电感向手指放射，属正常针感但不宜反复刺激以免神经损伤。现代用于腕管综合征、心悸、失眠、口臭。

───────────────

**○ 间使（经，属金）**
【定位】在腕横纹上 3 寸，掌长肌腱与桡侧腕屈肌腱之间。
【经气】手厥阴心包脉气所经过，为经穴。
【主治】心中空悬如有饥饿感、突然发狂、胸中动荡不安、恶风寒、呕吐、惊恐、里寒、气短、掌心发热、腋下肿、肘部拘挛、突发心痛、易惊、失音不能言语、咽喉如有物梗塞。
【刺灸法】可灸五壮，针入三分。（岐伯说：可灸以治"鬼邪"——即精神疾患。）
【译注】"可灸鬼邪"指古人对精神疾病的称呼（认为是鬼祟作怪）。间使是**治疟要穴**，现代研究证实针刺间使对疟疾发作有抑制作用（可能与调节免疫、体温中枢有关），这一古老经验在现代仍被验证。

───────────────

**○ 曲泽（合，属水）**
【定位】在肘横纹中央，肱二头肌腱的尺侧缘（肘微屈取穴）。
【经气】手厥阴心包脉气所汇入，为合穴。
【主治】心痛、易惊、身热、烦渴、口干、气逆、呕血、风疹、臂肘手腕不自主摇动。
【刺灸法】可灸三壮，针入二分，留针七呼。
【译注】⚠️ 曲泽处有**肘正中静脉**与**肱动脉**通过。现代常用曲泽点刺放血治疗急性胃肠炎呕吐、中暑。放血须严格消毒，有出血倾向者禁用。

◆ 六、手少阳三焦经（六穴）

**【经脉概要】**起于无名指末端（关冲），上行第四、五掌骨间（液门、中渚），至腕背（阳池），沿前臂外侧两骨（桡骨与尺骨）之间上行，过肘尖（天井），沿上臂外侧上肩，交出足少阳之后，入缺盆，布膻中，散络心包，下膈，依次属上、中、下三焦。支脉从膻中上出缺盆，上项，系耳后，出耳上角，再屈下颊至䪼。支脉从耳后入耳中，出耳前，至目锐眦。
**【穴序】**关冲（井）— 液门（荥）— 中渚（俞）— 阳池（原）— 支沟（经）— 天井（合）

───────────────

**○ 关冲（井，属金）**
【定位】在手无名指末端外侧（尺侧），距指甲角约一分处。
【经气】手少阳三焦脉气所出，为井穴。
【主治】喉痹、舌卷缩、口干、头痛、霍乱、胸中气噎、不思饮食、臂肘痛不能上举、目生翳膜、视物不清。
【刺灸法】针入一分，可灸一壮。**忌食猪肉、鱼、酒、面食及生冷等物**（针刺期间的饮食调护）。
【译注】"慎猪鱼酒面生冷"是古人针刺后的饮食禁忌，本意是防止"发物"诱发疾病。现代针灸对此并无严格要求，但针刺后注意清淡饮食、避免饮酒仍是合理的。

───────────────

**○ 液门（荥，属水）**
【定位】在手背第四、五指之间，指蹼缘后方赤白肉际处。
【经气】手少阳三焦脉气所流注，为荥穴。
【主治】惊悸、言语错乱、咽喉外侧肿、寒厥、手臂痛不能上下活动、疟疾寒热、目眩、头痛、突然耳聋、目赤涩痛、齿龈痛。
【刺灸法】针入二分，可灸三壮。

───────────────

**○ 中渚（俞，属木）**
【定位】在手背第四、五掌骨间凹陷中，液门穴后 1 寸。
【经气】手少阳三焦脉气所灌注，为俞穴。
【主治】热病汗不出、目眩、头痛、耳聋、目生翳膜、久疟、咽喉肿、肘臂痛、手指不能屈伸。
【刺灸法】针入二分，可灸三壮。
【译注】中渚是**耳鸣耳聋要穴**（与听宫、翳风配用）。现代用于突发性耳聋、梅尼埃病、手指屈伸不利（腱鞘炎）、肩周炎。

───────────────

**○ 阳池（原穴）**，一名别阳
【定位】在腕背横纹中央，指总伸肌腱与小指固有伸肌腱之间的凹陷中（腕背正中）。
【经气】手少阳三焦脉气所经过，为原穴。
【主治】寒热往来、疟疾、因跌扑损伤手腕而握物无力、肩臂痛不能上举。
【刺灸法】针入二分，留针三呼。**不可灸**（原文"不可灸"），饮食禁忌同前。
【译注】⚠️ 阳池是古代针灸"**禁灸穴**"之一（因腕背皮薄、肌腱浅表，灸易损伤肌腱）。现代亦以不灸为宜。此穴现代用于腕关节痛、糖尿病（三焦经主水液代谢，有研究用于糖尿病口渴多尿的辅助治疗）。

───────────────

**○ 支沟（经，属火）**
【定位】在腕背横纹上 3 寸，桡骨与尺骨之间。
【经气】手少阳三焦脉气所经过，为经穴。
【主治】热病汗不出、肩臂酸重、胁腋疼痛、四肢不能上举、霍乱、呕吐、口噤不开、突然失音不能言语。
【刺灸法】可灸七壮，针入二分。饮食禁忌同前。
【译注】支沟是**便秘要穴**，古今皆用。现代研究证实针刺支沟能促进结肠蠕动，治疗功能性便秘效果确切。也用于胁肋痛（肋间神经痛）、落枕。

───────────────

**○ 天井（合，属土）**
【定位】在肘尖（尺骨鹰嘴）后上方 1 寸凹陷中，屈肘取之。（甄权说：屈肘后一寸，叉手按膝头取之，在两筋骨间隙中。）
【经气】手少阳三焦脉气所汇入，为合穴。
【主治】心胸疼痛、咳嗽气逆、咳吐脓血、不思饮食、惊悸、抽搐、风痹、臂肘痛、握物无力。
【刺灸法】针入三分。
【译注】天井现代用于肘关节病、颈淋巴结核（瘰疬）、偏头痛。古书中天井是治瘰疬的要穴。

◆ 七、足厥阴肝经（五穴）

**【经脉概要】**起于足大趾外侧端（大敦），沿足背内侧上行（行间、太冲），经内踝前（中封），沿小腿内侧上行，至内踝上 8 寸处交出足太阴之后，上行膝腘内侧（曲泉），沿大腿内侧入阴毛中，绕阴器，抵小腹，挟胃属肝络胆，上贯膈，布胁肋，循喉咙之后，上入颃颡（鼻咽部），连目系，上出额，与督脉会于巅顶。支脉从目系下行颊里，环唇内。支脉从肝别贯膈，上注肺。
**【穴序】**大敦（井）— 行间（荥）— 太冲（俞）— 中封（经）— 曲泉（合）

───────────────

**○ 大敦（井，属木）**
【定位】在足大趾末端外侧（外侧为足背侧），距趾甲角约一分处，正当趾甲根与趾间毛之际。
【经气】足厥阴肝脉气所出，为井穴。
【主治】突发疝气、小便频数、遗尿、阴茎头部疼痛、心痛汗出、阴器上缩入腹、阴囊肿大偏坠、腹脐中痛、闷闷不乐、腹胀肿病、少腹痛、腹中发热、嗜睡、尸厥（状如死人）、**妇人血崩不止**。
【刺灸法】可灸三壮，针入三分，留针六呼。（内侧为隐白穴，属脾经；外侧为大敦，属肝经——两穴仅在足大趾内外侧之别。）
【译注】大敦是**治疝气与崩漏的要穴**。古人在大敦施灸治疝气"（灸）大敦七壮"，现代仍用于腹股沟疝的辅助治疗与功能性子宫出血。这个"内侧隐白、外侧大敦"的定位提示非常实用——初学者极易混淆。
- **尸厥**：突然昏倒、状如死人（呼吸微弱、脉搏细弱），类似现代的休克、晕厥、癔症性木僵。

───────────────

**○ 行间（荥，属火）**
【定位】在足背第一、二趾之间，趾蹼缘后方赤白肉际处。
【经气】足厥阴肝脉气所流注，为荥穴。
【主治】排尿困难、小便白浊（白浊）、寒疝、少腹肿、咳嗽气逆、呕血、腰痛不能俯仰、腹胀、心痛、面色青灰如死状、终日不得喘息、口㖞、四肢逆冷、咽喉干燥、烦渴、闭目不想视物、眼中流泪、善太息、癫疾、气短。
【刺灸法】可灸三壮，针入六分，留针十呼。
【译注】行间是**泻肝火第一穴**，现代用于高血压（肝阳上亢型）、青光眼、急性结膜炎、目赤肿痛、失眠、痛经、更年期烦躁。"行间"意为经气行走于趾间。

───────────────

**○ 太冲（俞，属土）**
【定位】在足背第一、二跖骨结合部前方的凹陷中（约当第一、二趾缝向上约 2 寸处）。
【经气】足厥阴肝脉气所灌注，为俞穴；又为**肝经原穴**。
【主治】腰痛牵引少腹痛、小便不利如淋证状、㿉疝、少腹肿、大便溏泄、遗尿、阴部疼痛、面目青色、胸胁支撑胀满、足部发凉、大便困难、呕血、**女子漏血不止**、小儿突发疝气、呕逆恶寒、咽喉干燥、肘肿、内踝前痛、痠软无力、腋下肿、马刀（腋下淋巴结肿）、口唇肿。
【刺灸法】针入三分，留针十呼，可灸三壮。
⚠️ **重要诊法**：**诊察太冲脉可以判断男子的生死预后**（"丸胗太冲脉，可诀男子病死生"——原文"丸胗"疑为"凡诊"之误）。
【译注】
- 太冲是**肝经最重要穴位**，与合谷并称"四关穴"（开四关），是疏肝理气、平肝熄风的核心组合。现代用于高血压、头痛、眩晕、抑郁焦虑、月经不调、痛经、青光眼。
- **诊太冲脉**：古人通过触摸足背动脉（足背动脉的搏动点就在太冲附近）判断气血盛衰与预后。这与现代检查**足背动脉搏动**（评估下肢血供、休克时外周灌注）的思路完全一致。
- ⚠️ 此处有足背动脉，针刺须避开血管。

───────────────

**○ 中封（经，属金）**
【定位】在足内踝前 1 寸，胫骨前肌腱内侧凹陷处（足背屈时肌腱显现，伸足时凹陷明显）。
【经气】足厥阴肝脉气所经过，为经穴。
【主治】疟疾、面色青灰、寒战、少腹肿、饮食不香、绕脐疼痛、足部逆冷、不思饮食、身体麻木不仁、寒疝牵引腰中痛、或身体微热。
【刺灸法】针入四分，留针七呼，可灸三壮。

───────────────

**○ 曲泉（合，属水）**
【定位】屈膝，在膝关节内侧横纹端上方，股骨内侧髁的后缘、半膜肌与半腱肌肌腱前缘的凹陷中。
【经气】足厥阴肝脉气所汇入，为合穴。
【主治】**女子血瘕**（腹中血块，按之如热汤浸股内）、少腹肿、阴挺出（子宫脱垂）、男子㿉疝、阴股疼痛、小便困难、胁肋支撑胀满、癃闭、气短、泄泻、四肢不能上举；实证则身热、目眩痛、汗不出、目䀮䀮、膝肿痛、筋脉拘挛不能屈伸、发狂、鼻出血、气喘呼叫、少腹痛牵引咽喉。
【刺灸法】针入六分，可灸三壮。（一说：在膝内侧屈曲处两筋之间凹陷中，又在膝部横纹头；治风劳失精、身体剧痛、泄泻下利脓血、阴部肿痛，可灸三壮，针入六分，留针十呼。）
【译注】曲泉是**泌尿生殖系统要穴**，现代用于前列腺炎、尿路感染、子宫脱垂、膝关节病、疝气。"血瘕"相当于现代的盆腔包块（子宫肌瘤、卵巢囊肿、子宫内膜异位症）。

◆ 八、足少阳胆经（六穴）

**【经脉概要】**起于目锐眦，上抵头角，下耳后，循颈行手少阳之前，至肩上，交出手少阳之后，入缺盆。支脉从耳后入耳中，出走耳前，至目锐眦后。支脉别锐眦，下大迎，合手少阳，抵䪼，下加颊车，下颈合缺盆，下胸中，贯膈络肝属胆，循胁里，出气街，绕毛际，横入髀厌（髋关节）中。直行者从缺盆下腋，循胸过季胁，下合髀厌中，沿大腿外侧下行，出膝外廉，下外辅骨之前，直下抵绝骨之端，下出外踝之前，循足背入第四、五趾之间。
**【穴序】**足窍阴（井）— 侠溪（荥）— 足临泣（俞）— 丘墟（原）— 阳辅（经）— 阳陵泉（合）

───────────────

**○ 足窍阴（井，属金）**
【定位】在足第四趾末端外侧，距趾甲角约一分处。
【经气】足少阳胆脉气所出，为井穴。
【主治】胁痛、咳嗽气逆不得喘息、手足烦热、汗不出、转筋、痈疽、头痛、心烦、喉痹、舌强、口干、肘不能上举、突然耳聋听不见人说话。
【刺灸法】可灸三壮，针入一分。
【译注】头部的"头窍阴"与足部第四趾的"足窍阴"同名，须区分。此处为**足窍阴**。

───────────────

**○ 侠溪（荥，属水）**
【定位】在足背第四、五趾之间，趾蹼缘后方赤白肉际处。
【经气】足少阳胆脉气所流注，为荥穴。
【主治】胸胁支撑胀满、寒热往来、汗不出、目外眦赤、目眩、颊颌肿、耳聋、胸中痛不能转侧、疼痛游走不定（痛无常处）。
【刺灸法】可灸三壮，针入三分。

───────────────

**○ 足临泣（俞，属木）**
【定位】在足背第四、五跖骨结合部前方的凹陷中（侠溪穴后 1.5 寸）。
【经气】足少阳胆脉气所灌注，为俞穴；又为**八脉交会穴之一，通带脉**。
【主治】胸中胀满、锁骨上窝与腋下肿、马刀（腋下淋巴结肿）、齿痛、颊部与天牖（颈部）肿、痠软无力、目眩、枕骨与颅骨交界处疼痛、寒战发抖、妇人月经不调、季胁支撑胀满、乳痈（急性乳腺炎）、心痛、周痹（全身游走性痹痛）、疼痛游走不定、厥逆、气喘不能行走、疟疾每日发作。
【刺灸法】可灸三壮，针入二分。
【译注】足临泣通带脉，是**治乳腺病与月经不调的要穴**，现代用于乳腺增生、急性乳腺炎、偏头痛、胁痛。与头临泣（头部）同名，须区分。

───────────────

**○ 丘墟（原穴）**
【定位】在足外踝前下方，趾长伸肌腱外侧的凹陷中（外踝前下缘）。
【经气】足少阳胆脉气所经过，为原穴。
【主治】胸胁胀满疼痛不得喘息、久疟寒战、腋下肿、痿厥（肢体痿软厥冷）坐不能起、髋关节痛、目生翳膜、腿痠转筋、突发疝气、少腹坚硬、寒热往来、颈肿。
【刺灸法】可灸三壮，针入五分，留针七呼。
【译注】丘墟现代用于踝关节扭伤（外踝扭伤）、胆囊炎、坐骨神经痛、胁痛。⚠️ 踝扭伤急性期（24–48 小时内）不宜针刺局部，应先冷敷加压。

───────────────

**○ 阳辅（经，属火）**
【定位】在小腿外侧，外踝尖上 4 寸，腓骨前缘稍前方。
【经气】足少阳胆脉气所经过，为经穴。
【主治】腰部寒冷沉重如坐在水中（腰溶溶如坐水中）、膝下皮肤浮肿、筋脉拘挛、各个关节都痛、疼痛游走不定、腋下肿、喉痹、马刀、膝部痠软、风痹麻木不仁。
【刺灸法】可灸三壮，针入五分，留针七呼。
【译注】"腰溶溶如坐水中"是对腰部冷重感的经典描述，现代可见于慢性腰肌劳损、腰椎间盘突出、肾阳虚型腰痛。

───────────────

**○ 阳陵泉（合，属土）**
【定位】在小腿外侧，腓骨小头前下方凹陷中（屈膝 90°，膝外下方，腓骨小头前下缘）。
【经气】足少阳胆脉气所汇入，为合穴；又为**八会穴之一——筋会阳陵泉**。
【主治】膝部伸而不能屈、冷痹、足部麻木不仁、偏风半身不遂、足部发凉无血色。
【刺灸法】针入六分，**得气后用泻法，并且要久留针**（这是取效的关键）；也可以用蹲坐的姿势取穴。灸也很好，每日灸七壮，至七七四十九壮为止。
【译注】
- 阳陵泉是**筋会**，凡筋病（肌腱、韧带、肌肉痉挛、关节炎、运动损伤）都取此穴，与太渊（脉会）、大杼（骨会）、膈俞（血会）等并称八会穴。现代用于肩周炎、膝关节炎、坐骨神经痛、胆绞痛、腓总神经麻痹、中风后遗症（下肢瘫）。
- **"宜久留针"**提示这是治疗筋病的关键——现代研究证实，留针时间（20–40 分钟）与镇痛效果正相关。
- ⚠️ 此穴深部有**腓总神经**经过，针刺时可有麻电感向足背放射，属正常针感，但不可过度刺激。

◆ 九、足太阴脾经（五穴）

**【经脉概要】**起于足大趾内侧端（隐白），沿足内侧赤白肉际上行，过内踝前（商丘），沿小腿内侧胫骨后缘上行，在内踝上 8 寸处交出足厥阴之前，上行膝股内侧前缘（阴陵泉），入腹属脾络胃，上膈挟咽，连舌本，散舌下。支脉从胃别上膈，注心中。
**【穴序】**隐白（井）— 大都（荥）— 太白（俞）— 商丘（经）— 阴陵泉（合）

───────────────

**○ 隐白（井，属木）**
【定位】在足大趾末端内侧，距趾甲角约一分处。
【经气】足太阴脾脉气所出，为井穴。
【主治】腹胀、气喘胀满不能安卧、呕吐、饮食不下、突然泄泻、鼻出血、突然昏厥不识人（卒尸厥）、足部发凉不能温。
【刺灸法】针入三分。**妇人月经过期不来的，针刺此穴立刻可愈**（古人经验）。
【译注】隐白是**止血要穴**（脾统血），古今皆用灸隐白治月经过多、崩漏、功能性子宫出血。现代研究证实灸隐白可促进子宫收缩、减少出血。此穴也是脾经井穴，用于急救昏迷。

───────────────

**○ 大都（荥，属火）**
【定位】在足内侧，第一跖趾关节前下方赤白肉际凹陷中。
【经气】足太阴脾脉气所流注，为荥穴。
【主治】热病汗不出、手足逆冷、腹部胀满、多呃逆、烦热闷乱、呕吐上逆、目眩。
【刺灸法】可灸三壮，针入三分。
【译注】大都现代用于消化不良、腹胀、糖尿病（脾经穴有调节糖代谢作用的研究报道）、足趾痛。

───────────────

**○ 太白（俞，属土）**
【定位】在足内侧，第一跖趾关节后下方赤白肉际凹陷中（第一跖骨小头后缘）。
【经气】足太阴脾脉气所灌注，为俞穴；又为**脾经原穴**。
【主治】身热烦闷、腹胀、饮食不消化、呕吐、泄泻脓血、腰痛、大便难。
【刺灸法】可灸三壮。
【译注】太白是**脾胃病要穴**，现代用于胃炎、肠炎、消化不良、腹泻、便秘、糖尿病、下肢乏力。与足三里配用是健脾经典组合。

───────────────

**○ 商丘（经，属金）** ⚠️【原书此穴缺，据《灵枢》《甲乙经》补入】
【定位】在足内踝前下方凹陷中，舟骨结节与内踝尖连线中点。
【经气】足太阴脾脉气所经过，为经穴。
【主治】腹胀、肠鸣、腹泻、便秘、消化不良、黄疸、倦怠嗜睡、足踝痛、痔疮、小儿惊风。
【刺灸法】针入三分，可灸三壮。
【译注】本穴原电子本缺失（经脉穴序至"太白"即中断，跳至足阳明胃经的"解溪"）。为使经脉穴序完整，据《灵枢·本输》与《针灸甲乙经》补入。

───────────────

**○ 阴陵泉（合，属水）** ⚠️【原书此穴缺，据《灵枢》《甲乙经》补入】
【定位】在小腿内侧，胫骨内侧髁后下方凹陷中（与阳陵泉相对，胫骨内侧髁下缘）。
【经气】足太阴脾脉气所汇入，为合穴。
【主治】腹胀、水肿、黄疸、小便不利或失禁、遗尿、尿潴留、膝痛、阴部痛、带下、月经不调、痛经、下肢水肿。
【刺灸法】针入五分至一寸，可灸三至五壮。
【译注】阴陵泉是**利水消肿要穴**，"合治内腑"，善治水液代谢障碍（水肿、小便不利、腹水）。现代用于肾炎水肿、肝硬化腹水、尿路感染、膝关节炎、妇科带下病。与阳陵泉（筋会，治筋病）内外相对，一治水一治筋，是很有意思的对应关系。

◆ 十、足阳明胃经（六穴）⚠️【原书此经缺，据《灵枢》《甲乙经》及本书误置内容补正】

【说明】原电子本足太阴脾经篇内，在"太白"之后直接接"解溪""三里"二穴，而解溪（经）、足三里（合）实属**足阳明胃经**。这是电子文本整理时的条目错位与缺漏。为使十二经完整，此处据《灵枢·本输》《针灸甲乙经》补出足阳明胃经五输穴，并将误置于脾经篇的"解溪""三里"归回本经。

**【经脉概要】**起于鼻旁（迎香），交鼻根部，旁会足太阳，下循鼻外，入上齿，还出挟口，环唇，下交承浆，退循下颌（大迎），上耳前，过客主人，循发际，至额颅。支脉从大迎前下人迎，循喉咙，入缺盆，下膈属胃络脾。直行者从缺盆下乳内廉，下挟脐，入气街中。支脉从胃口下循腹里，下至气街而合，下行髀关，抵伏兔，下膝膑中，循胫外廉，下足跗，入中趾内间。
**【穴序】**厉兑（井）— 内庭（荥）— 陷谷（俞）— 冲阳（原）— 解溪（经）— 足三里（合）

───────────────

**○ 厉兑（井，属金）** ⚠️【补】
【定位】在足第二趾末端外侧，距趾甲角约一分处。
【经气】足阳明胃脉气所出，为井穴。
【主治】牙痛、鼻出血、咽喉肿痛、热病、多梦易惊（梦魇）、腹胀、足背肿痛、昏厥。
【刺灸法】针入一分，可灸三壮。
【译注】厉兑是**安神要穴**，古人用于治"梦魇不宁"（噩梦惊醒）。现代用于失眠、多梦、牙痛、鼻出血。

───────────────

**○ 内庭（荥，属水）** ⚠️【补】
【定位】在足背第二、三趾之间，趾蹼缘后方赤白肉际处。
【经气】足阳明胃脉气所流注，为荥穴。
【主治】牙痛、咽喉肿痛、鼻出血、胃痛、腹胀、腹泻、便秘、足背肿痛、热病、口渴、口臭。
【刺灸法】针入三分，可灸三壮。
【译注】内庭是**清胃火要穴**，现代用于牙痛、牙周炎、口臭、胃炎（胃热型）、三叉神经痛（上颌支）。

───────────────

**○ 陷谷（俞，属木）** ⚠️【补】
【定位】在足背第二、三跖骨结合部前方的凹陷中（内庭穴后 2 寸）。
【经气】足阳明胃脉气所灌注，为俞穴。
【主治】面目浮肿、水肿、肠鸣腹痛、腹水、足背肿痛、热病、汗不出、疟疾。
【刺灸法】针入五分，可灸三壮。
【译注】陷谷善治水肿（"面目浮肿"），与阴陵泉配用是利水经典组合。

───────────────

**○ 冲阳（原穴）** ⚠️【补】
【定位】在足背最高处，第二、三跖骨与楔状骨之间，足背动脉搏动处（解溪穴下约 1.5 寸）。
【经气】足阳明胃脉气所经过，为原穴。
【主治】胃痛、腹胀、食欲不振、口眼歪斜、面肿、牙痛、足背肿痛、足痿无力、狂证。
【刺灸法】针入三分，避开动脉；**禁灸**（原文类书多列为禁灸穴）。
【译注】⚠️ 冲阳处为**足背动脉**，古人通过诊察冲阳脉判断胃气存亡（"冲阳脉绝，胃气败"）。现代临床仍用触摸足背动脉评估下肢血供。针刺须避开血管，禁灸以防血管损伤。

───────────────

**○ 解溪（经，属火）** ⚠️【原书误置于脾经篇，此据经脉归属移回】
【定位】在足背踝关节横纹中央，拇长伸肌腱与趾长伸肌腱之间（解溪穴正当冲阳后 1.5 寸，踝关节前横纹中央）。
【经气】足阳明胃脉气所经过，为经穴。
【主治】头面浮肿、面部发黑（颜黑）、气上逆冲、腹胀、大便下坠重坠感（下重）、易惊、膝部与大腿肿、转筋、目眩、头痛、癫疾、心烦、悲伤哭泣、霍乱、头风、面赤、目赤。
【刺灸法】针入五分，可灸三壮。
【译注】解溪现代用于踝关节扭伤、足背痛、头痛、腹胀、癔症。"颜黑"（面色晦暗）在此提示胃经气血瘀滞。

───────────────

**○ 足三里（合，属土）** ⚠️【原书误置于脾经篇，此据经脉归属移回】
【定位】在小腿前外侧，膝眼下 3 寸，胫骨前嵴外一横指（犊鼻穴下 3 寸，胫骨前肌上）。
【经气】足阳明胃脉气所汇入，为合穴；又为**胃下合穴**（"合治内腑"）。
【主治】胃中寒冷、心腹胀满、胃气不足、闻到食物气味（食欲异常）、肠鸣、腹痛、饮食不消化。
- **秦承祖说**：诸病皆可治，包括食积、水气、蛊毒、癖块、四肢沉重胀满、膝部痠痛、视物不明。
- **华佗说**：治五劳羸瘦、七伤虚乏、胸中瘀血、乳痈。
- **《外台》《明堂》说**：**人年三十以上，若不灸足三里，冷气上冲于目**（意为三十岁后常灸足三里可防病保健）。
【刺灸法】可灸三壮，针入五分（现代常用 1–2 寸）。
【译注】
- 足三里是**中医第一保健大穴**，古今医家一致推崇。民间谚语"若要身体安，三里常不干"（指常灸三里使局部起泡化脓，形成瘢痕灸，虽有效但现代已不主张）。
- 现代研究证实：针刺或艾灸足三里能调节胃肠动力与胃酸分泌、增强免疫功能（提高白细胞吞噬能力、NK 细胞活性）、抗炎、抗疲劳、改善微循环。这是中医穴位研究最充分的穴位之一。
- ⚠️ 原文"针入五分"较浅，现代常用 1.0–2.0 寸（25–50 mm），并强调"得气"（酸麻胀感向足背传导）是取效的关键。
- ⚠️ 原文"秦丞相"当指秦承祖（南朝刘宋医家），"秦丞相"为后世传抄时的讹称。

◆ 十一、足少阴肾经（五穴）

**【经脉概要】**起于足小趾下，斜走足心（涌泉），出舟骨粗隆下（然谷），沿内踝后（太溪），入足跟，上行小腿内侧后缘，出腘窝内侧，上行大腿内侧后缘，贯脊属肾络膀胱。直行者从肾上贯肝膈，入肺中，循喉咙，挟舌本。支脉从肺出络心，注胸中。
**【穴序】**涌泉（井）— 然谷（荥）— 太溪（俞）— 复溜（经）— 阴谷（合）

───────────────

**○ 涌泉（井，属木）**，一名地冲
【定位】在足底，蜷足时足心最凹陷中（约当足底前 1/3 与后 2/3 交界处）。
【经气】足少阴肾脉气所出，为井穴。
【主治】腰痛、大便困难、心中结热、风疹、风痫（癫痫）、心脏病、不思饮食、妇人无子、咳嗽、身热、喉痹、胸胁胀满、目眩、男子如蛊（腹胀如鼓）、女子如妊娠（腹大似孕）、五个脚趾端都痛、足不能着地。
【刺灸法】可灸三壮，针入五分，**不可令其出血**。
- ⚠️ **古代医案**：淳于意（西汉名医）说，汉代北齐王的乳母（阿母）患足下热、气喘病，他诊断为"热厥"，**刺足心（涌泉）而立刻痊愈**。
【译注】
- 涌泉是**急救与保健要穴**，现代用于昏迷休克急救、高血压（引火归元）、失眠、口腔溃疡（虚火上炎）、足底痛。古人治"足下热"用涌泉，正是"上病下取、引火下行"的思路。
- ⚠️ 涌泉部位痛觉极为敏感（足底神经末梢密集），针刺疼痛剧烈，现代多以艾灸或按摩（搓涌泉）代替，尤其用于老年保健与失眠。
- "不可令出血"是重要提示：足底血管丰富且不易压迫止血，出血后易形成血肿。

───────────────

**○ 然谷（荥，属火）**，一名龙渊
【定位】在足内侧，舟骨粗隆下方赤白肉际凹陷中（内踝前下方）。
【经气】足少阴肾脉气所流注，为荥穴。
【主治】咽喉内侧肿、心中恐惧如有人要抓捕自己、流涎、气喘息短、足背肿不能着地、寒疝、少腹胀、上冲胸胁、咳嗽唾血、喉痹、淋沥、**女子不孕、男子遗精**、小腿痠软不能久立、足部忽寒忽热、舌体弛纵、烦闷、消渴（糖尿病）、初生小儿脐风口噤（新生儿破伤风）、痿厥、洞泄。
【刺灸法】可灸三壮，针入三分，**不宜见血**。
【译注】
- 然谷是**生殖系统要穴**，古今皆用于不孕、遗精、月经不调。现代用于糖尿病（消渴）、咽喉炎、尿路感染、更年期综合征。
- ⚠️ **"初生小儿脐风口噤"= 新生儿破伤风**。这是古代新生儿死亡的主要原因之一，由断脐时器具不洁、感染破伤风梭菌所致。古人用灸然谷治疗，效果有限；现代通过**无菌接生 + 孕妇破伤风疫苗免疫**，已基本消灭此病。这个条目是医学史的重要见证。

───────────────

**○ 太溪（俞，属土）**
【定位】在足内踝尖与跟腱之间的凹陷中（内踝后方，动脉搏动处）。
【经气】足少阴肾脉气所灌注，为俞穴；又为**肾经原穴**。
【主治】久疟、咳嗽气逆、**心痛如锥刺心、手足寒冷至关节、喘息者死**（这是危重预后判断）、呕吐、口中有胶粘感、多嗳气、寒疝、热病汗不出、倦怠嗜卧、小便发黄、消瘅（糖尿病）、大便困难、咽喉肿、唾血、癖块、寒热往来、咳嗽、不思饮食、腹胁痛、脊背瘦削、手足厥冷。
【刺灸法】可灸三壮，针入三分。
【译注】
- 太溪是**补肾第一要穴**，现代用于肾虚诸证（腰膝酸软、耳鸣、脱发、记忆力减退）、糖尿病、肾炎、月经不调、失眠、足跟痛。
- ⚠️ **"心痛如锥刺，手足寒至节，喘息者死"**：这是古人对**急性心肌梗死合并心源性休克**的预后判断——剧烈胸痛、四肢厥冷（休克外周灌注不足）、喘息（急性左心衰肺水肿）。这组症状出现时死亡率极高，古今皆然。现代应立即呼叫急救、嚼服阿司匹林、吸氧、尽快行 PCI（冠脉介入）开通血管。
- ⚠️ 此处有**胫后动脉**经过，针刺须避开血管。古人通过诊察太溪脉判断肾气存亡，与现代触摸胫后动脉评估灌注的思路一致。

───────────────

**○ 复溜（经，属金）**，一名昌阳、一名伏白
【定位】在小腿内侧，太溪穴直上 2 寸，跟腱前缘。
【经气】足少阴肾脉气所经过，为经穴。
【主治】腰脊内牵引疼痛、不能俯仰起坐、目䀮䀮、易怒、多言、舌干、口涎自出、足部痿软无力、收摄不住、下肢寒冷不能自温、腹中雷鸣、腹胀如鼓、四肢浮肿、**十水病**（各种水肿）、小便呈青、赤、黄、白、黑五色（按五色分别取穴：青取井、赤取荥、黄取俞、白取经、黑取合）、血痔、泄泻后浮肿、五淋、小便如散（尿失禁）、大骨寒热、汗出不止。
【刺灸法】可灸五壮，针入三分，留针三呼。
【译注】
- 复溜是**水肿与汗证要穴**，现代用于肾炎水肿、肝硬化腹水、盗汗、自汗、下肢水肿、腹泻、腰痛。"复溜"意为肾水流复，恢复水液代谢。
- **"十水病"与五色取穴法**：这是古代按水肿颜色/性质分类取穴的方法（青取井穴、赤取荥穴、黄取俞穴、白取经穴、黑取合穴），体现了五输穴的五行配属运用。理论精巧，但临床应用较少，作为医学史了解。
- ⚠️ 水肿必须查明原因（心、肾、肝、甲状腺、营养不良、静脉/淋巴回流障碍），不可只靠针灸。

───────────────

**○ 阴谷（合，属水）**
【定位】在腘窝内侧，屈膝时半腱肌腱与半膜肌腱之间（委中穴内侧）。
【经气】足少阴肾脉气所汇入，为合穴。
【主治】膝痛如锥刺、不能屈伸、舌体弛纵、流涎、烦躁气逆、排尿困难、少腹拘急牵引阴部疼痛、大腿内侧疼痛、**妇人漏下不止**、腹胀满不得喘息、小便发黄、男子如蛊（腹胀如鼓）、女子如妊娠（腹大似孕）。
【刺灸法】可灸二壮，针入四分，留针七呼。
【译注】阴谷现代用于膝关节炎、尿路感染、前列腺炎、月经不调、阳痿、遗精。⚠️ 腘窝内有胫神经与腘血管，针刺须由医师操作。

◆ 十二、足太阳膀胱经（六穴）

**【经脉概要】**起于目内眦（睛明），上额交巅。支脉从巅至耳上角。直行者从巅入络脑，还出别下项，循肩膊内，挟脊抵腰中，入循膂，络肾属膀胱。支脉从腰中下挟脊，贯臀，入腘中。支脉从膊内左右别下贯胛，挟脊内，过髀枢，循髀外后廉下合腘中，下贯腨内，出外踝之后（昆仑），循京骨，至小趾外侧（至阴）。
**【穴序】**至阴（井）— 足通谷（荥）— 束骨（俞）— 京骨（原）— 昆仑（经）— 委中（合）

───────────────

**○ 至阴（井，属金）**
【定位】在足小趾末端外侧，距趾甲角约一分处。
【经气】足太阳膀胱脉气所出，为井穴。
【主治】目生翳膜、鼻塞、头重、风寒从足小趾起、脉痹上下牵引、胸胁痛游走不定、转筋、寒疟、汗不出、心烦、足下发热、小便不利、遗精。
【刺灸法】针入二分，可灸三壮。
【译注】⚠️ **至阴是矫正胎位不正（臀位、横位）的著名穴位**——艾灸至阴穴可使约 70% 的胎位不正转为头位（现代多项临床研究支持，机制可能与刺激引起胎儿活动增加有关）。这是针灸在产科最有价值的应用之一。⚠️ 孕妇使用须由专业医师操作（一般孕 28–34 周，每日 1–2 次，每次 15–20 分钟），有前置胎盘、先兆早产者禁用。

───────────────

**○ 足通谷（荥，属水）**
【定位】在足外侧，第五跖趾关节前缘赤白肉际凹陷中。
【经气】足太阳膀胱脉气所流注，为荥穴。
【主治】头重、目眩、易惊、牵引鼻塞鼻出血、颈项痛、目䀮䀮。（甄权说：可治水饮结聚停留、胸部胀满、饮食不化。）
【刺灸法】可灸三壮，针入二分。

───────────────

**○ 束骨（俞，属木）**
【定位】在足外侧，第五跖趾关节后方赤白肉际凹陷中。
【经气】足太阳膀胱脉气所灌注，为俞穴。
【主治】腰痛如折、小腿如结（拘急）、耳聋、恶风寒、目眩、颈项不能回顾、目内眦赤烂。
【刺灸法】可灸三壮，针入三分。

───────────────

**○ 京骨（原穴）**
【定位】在足外侧，第五跖骨粗隆下方赤白肉际凹陷中。
【经气】足太阳膀胱脉气所经过，为原穴。
【主治】膝痛不能屈伸、目内眦赤烂、发疟寒热、易惊、不思饮食、筋脉拘挛、足胫痛、髋关节痛、颈项强、腰背不能俯仰、鼻出血不止、目眩。
【刺灸法】针入三分，可灸七壮。

───────────────

**○ 昆仑（经，属火）**
【定位】在足外踝尖与跟腱之间的凹陷中。
【经气】足太阳膀胱脉气所经过，为经穴。
【主治】腰骶部疼痛（腰尻痛）、足跟肿不能着地、鼻塞鼻出血、脚如结（拘急）、踝如裂（剧痛）、头痛、肩背拘急、咳嗽气喘、突发胀满、阴部肿痛、小儿发痫抽搐。
【刺灸法】艾炷如小麦粒大，可灸三壮，针入三分。
【译注】
- 昆仑是**腰腿痛与头痛要穴**，现代用于坐骨神经痛、急性腰扭伤、足跟痛、偏头痛、踝关节扭伤。
- ⚠️⚠️ **孕妇禁用昆仑穴**，与合谷、三阴交同列，有兴奋子宫、引发宫缩的作用。这是针灸最重要的妊娠禁忌之一。

───────────────

**○ 委中（合，属土）**
【定位】在腘窝横纹中央，股二头肌腱与半腱肌腱之间（腘窝正中）。
【经气】足太阳膀胱脉气所汇入，为合穴；又为**膀胱下合穴**。
【主治】腰部沿脊柱沉重疼痛、遗尿、腰部沉重不能举动、身体风痹、髋关节痛。**可以放血**——（放血后）顽固的皮疹都能痊愈。委中是"血郄"（血之郄穴）。热病汗不出、足部热厥逆、胀满、膝部不能屈伸的，**取其经血（放血）立刻痊愈**。
【刺灸法】点刺腘窝浅表静脉放血。
【译注】
- ⚠️⚠️ **委中放血是古代最常用的急救放血法**，用于急性腰扭伤（"腰背委中求"）、中暑、急性胃肠炎、丹毒、顽固性皮肤病。现代研究显示放血可降低局部压力、改善微循环、促进炎性物质清除。
- ⚠️⚠️ **严重风险警示**：腘窝内有**腘动脉、腘静脉与胫神经**。放血只能点刺浅表的**小隐静脉属支**（腘窝浅层），深度不超过 2–3 mm。**绝对不可深刺或误伤腘动脉**——腘动脉破裂可致大出血、肢体缺血坏死甚至休克死亡。此操作**必须由经验丰富的执业医师进行，严格执行无菌操作**。有出血倾向（血友病、血小板减少、服用抗凝药者）、局部感染、静脉曲张严重者禁用。
- **"腰背委中求"**是针灸最著名的口诀之一——腰背部疼痛取委中。

【附录】针灸安全要点（今人补）

**一、绝对禁忌**
1. ⚠️ **孕妇禁针/禁灸穴**：合谷、三阴交、昆仑、至阴（慎用）、肩井、缺盆，以及腰腹部穴、骶部穴。这是针灸最重要的禁忌。
2. ⚠️ **出血倾向者禁针**：血友病、血小板减少、正在服用抗凝药（华法林、利伐沙班等）者。
3. ⚠️ **重要脏器部位禁深刺**：胸背部（防气胸）、颈部（防颈动脉窦反射、大血管损伤）、眼周（防眼球损伤）、后颈与枕部（防延髓损伤）。
4. ⚠️ **皮肤感染、溃疡、肿瘤部位禁针。**
5. ⚠️ **极度饥饿、疲劳、醉酒、大汗、大出血后禁针**（易发生晕针）。

**二、必须遵守的操作规范**
1. 针具必须**一次性使用**（严禁重复使用，防止乙肝、丙肝、HIV 传播）。
2. 皮肤严格消毒（75% 酒精或碘伏）。
3. 施术者必须具备执业资质。**针灸是医疗行为，不是保健按摩。**
4. 施术后可能出现**晕针**（头晕、恶心、出冷汗、面色苍白），应立即平卧、饮温水，严重者需急救。
5. 弯针、滞针、断针等意外需专业处理。

**三、古人留下的宝贵经验**
1. **禁灸穴**：经渠（动脉处）、阳池（腕背肌腱处）、冲阳（足背动脉处）——这些部位血管或肌腱浅表，灸疗易致损伤。古人的禁忌是有解剖依据的。
2. **诊脉判断预后**：诊太溪脉（肾气）、冲阳脉（胃气）、太冲脉（肝气）、足背动脉（外周灌注），与现代检查动脉搏动评估循环状态一致。
3. **"得气"是取效关键**：阳陵泉条下特别注明"宜久留针"，说明古人已认识到针感与留针时间对疗效的影响。现代研究证实"得气"与临床疗效正相关。
4. **缪刺法（交叉取穴）**：商阳条下"右取左，左取右"，与现代神经解剖的对侧支配原理吻合。

**四、本书的现代价值**
1. **"是动病/所生病"的经脉辨证体系**：把全身症状按十二经归类，是中医"经络辨证"的源头，至今仍是针灸临床选经配穴的依据。
2. **症状群描述的准确性**：如膀胱经"腰似折、腘如结、腨如裂"（坐骨神经痛）、胃经"弃衣而走、上高而歌"（躁狂发作）、心经"臂厥"（心绞痛放射痛），显示古人观察之精微。
3. **五输穴的五行配属与主治规律**：井主心下满、荥主身热、俞主体重节痛、经主喘咳寒热、合主逆气而泄（《难经·六十八难》），是针灸配穴的理论基石。
4. **八会穴与八脉交会穴**：书中出现的脉会太渊、筋会阳陵泉、后溪通督脉、临泣通带脉，至今仍是临床高频用穴。
